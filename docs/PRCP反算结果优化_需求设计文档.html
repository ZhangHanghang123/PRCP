需求背景与目标

2.1 背景

组合反算结果驾驶舱初期存在四个问题：

编号问题影响
P1「大类分布」取的是反算结果的预测月余额 切到 M24 时分布图跟着变，用户无法判断「当前账户结构长什么样」
P2缺少节点级余额明细与走势 只能看到大类占比，看不到「哪个科目在涨、涨多少」
P3无导出能力 汇报场景需手工截图/复制，无法留痕
P4KPI 卡片只有孤立数值 看不到「离目标还有多远」「比基期好了还是差了」

2.2 目标

  • 建立基准日当前余额与当月预测余额两套可切换口径，覆盖「现状」与「预测」两个视角
  • 提供节点级与层级汇总两种粒度的余额展示与走势
  • 提供结构化导出（xlsx），含账户册树、层级汇总、口径说明
  • 为每个 KPI 补充基期对比项与目标达成进度，让数值可被解读

2.3 设计原则

原则说明
口径唯一当前期与基期、图表与导出，必须走同一套取值函数，杜绝口径漂移
末级口径统一「末级节点」判定链：prcp_data_basic.is_leaf → path 前缀推断
父节点不重复父级汇总一律由末级节点上卷（roll-up）计算，不采信父节点自身值
量纲可解释目标与实际量级不可比时（相差 3 个数量级以上），完成率置空而非给出荒谬数字
口径可见静态字段必须标注「固定/不随预测月变化」，避免误判为功能失效

末级节点prcp_data_basic.is_leaf = 1无 basic 行时回退 path 前缀推断；不采信 prcp_data_reverse.is_leaf

完成率按 constraint_type 换算GE=实际/目标；LE=目标/实际；EQ=1−|差|/|目标|

5.2 公共查询条件

① 组合方案定位

-- 用途：取得 coa_scheme_id / base_date / 账户册方案编码 SELECT s.id, s.scheme_name, s.coa_scheme_id, s.data_date, s.horizon_months, c.scheme_code AS coa_code, c.scheme_name AS coa_name FROM prcp_reverse_scheme s LEFT JOIN prcp_coa_scheme c ON c.id = s.coa_scheme_id WHERE s.scheme_code = :sc AND s.is_deleted = 0
条件参数说明
scheme_code = :scURL 参数组合方案编码，缺省 2026
is_deleted = 0常量软删除过滤，全表统一约定
LEFT JOIN prcp_coa_scheme—取账户册方案编码，供指标表关联使用

② Run 定位（缺省取最新 SUCCESS）

-- 用途：确定本次展示/导出的执行批次 SELECT id FROM prcp_reverse_run WHERE scheme_id = :sid AND status = 'SUCCESS' AND is_deleted = 0 ORDER BY id DESC LIMIT 1

URL 传入 run_id 时直接使用；否则按上式取最新成功批次。失败/进行中的批次不参与展示。

③ 测算期月份序列

-- 用途：确定 M1~M24 的 (offset, data_date) 映射 SELECT DISTINCT date_offset, data_date FROM prcp_data_reverse WHERE scheme_code = :sc AND run_id = :rid AND is_deleted = 0 AND offset_unit = 'M' AND date_offset >= 1 ORDER BY date_offset ASC
为什么 date_offset >= 1：prcp_data_reverse 中 date_offset = 0 与 1 指向同一个 data_date（基准月），属重复行。 过滤掉 0 后得到 24 个不重复月份（M1~M24）。

命中索引：uk_node_date(scheme_code, run_id, coa_node_id, data_date, date_offset) 前缀命中；idx_run(run_id) 辅助。

④ 末级节点判定（口径链，两级）

-- 第一级（权威）：prcp_data_basic.is_leaf SELECT b.node_code, MAX(b.is_leaf) FROM prcp_data_basic b JOIN prcp_coa_node n ON n.id = b.coa_node_id WHERE n.scheme_id = :sid AND n.is_deleted = 0 AND b.is_deleted = 0 GROUP BY b.node_code
-- 第二级（兜底）：path 前缀推断「有子节点则非末级」 -- 存在 M 使 M.path 以 N.path + "/" 开头 ⇒ N 非末级
⚠️ 不可使用 prcp_data_reverse.is_leaf
方案 / Run节点数is_leaf=1 行数说明
2026 / run 3136900标记完整，可用
REV_ANT_REG / run 9570标记全为 0，且 category 为 NULL
REV_DNN_REG / run 8570同上
REV_NLS_REG / run 10570同上
若直接用 prcp_data_reverse.is_leaf = 1 过滤，后三个方案将返回空数据。

⑤ 5 指标取值（当前期与基期共用）

-- 优先按账户册方案编码取 SELECT node_code, metric_type, current_value FROM prcp_metric_coefficient WHERE is_deleted = 0 AND scheme_code = :sc -- = 账户册方案编码，如 ZX_COA AND data_date = :dd -- 当前期 data_date 或基期 data_date AND node_code IN ({ph}) AND metric_type IN ({ph2}) -- ROE/CET1/LCR/NSFR/DELTA_EVE -- 无数据时回退（兼容 ZXCOA_V1 历史数据） SELECT node_code, metric_type, current_value FROM prcp_metric_coefficient WHERE is_deleted = 0 AND data_date = :dd AND node_code IN ({ph}) AND metric_type IN ({ph2})
条件说明
scheme_code = :sc注意是账户册方案编码（ZX_COA），不是组合方案编码
data_date = :dd当前期用所选月份的 data_date；基期用 date_offset=1 的 data_date
回退分支该账户册方案无指标数据时，去掉 scheme_code 条件再查一次

① 基准日余额（FR-01）

-- 步骤 1：定位基准日（优先方案基准日，无则取该方案最新可用日） SELECT MAX(b.data_date) FROM prcp_data_basic b JOIN prcp_coa_node n ON n.id = b.coa_node_id WHERE n.scheme_id = :sid AND n.is_deleted = 0 AND b.is_deleted = 0 AND (:dd IS NULL OR b.data_date <= :dd) -- :dd = 方案基准日 -- 步骤 2：取该日全部节点余额（同时建立 node_code → is_leaf 映射） SELECT b.node_code, b.current_balance, n.path, b.is_leaf FROM prcp_data_basic b JOIN prcp_coa_node n ON n.id = b.coa_node_id WHERE n.scheme_id = :sid AND n.is_deleted = 0 AND b.is_deleted = 0 AND b.data_date = :dd

命中索引：uk_node_date_offset(coa_node_id, data_date, date_offset, offset_unit)； idx_node(coa_node_id)、idx_date(data_date) 辅助。

② 预测月余额（FR-01b / FR-02 / FR-04）

-- 单月（快照接口用） SELECT coa_node_id, node_code, current_balance, avg_balance, weighted_rate, interest_amount, risk_weight FROM prcp_data_reverse WHERE scheme_code = :sc AND run_id = :rid AND date_offset = :do AND offset_unit = 'M' AND is_deleted = 0 -- 全序列（走势/导出用） SELECT date_offset, node_code, node_name, category, current_balance FROM prcp_data_reverse WHERE scheme_code = :sc AND run_id = :rid AND is_deleted = 0 AND offset_unit = 'M' AND date_offset >= 1 ORDER BY date_offset ASC

③ 目标约束（FR-10）

SELECT kpi_code, target_name, target_value, constraint_type, weight, horizon_month FROM prcp_reverse_target WHERE scheme_id = :sid AND is_deleted = 0 ORDER BY sort_order

命中索引：idx_scheme(scheme_id)。当前方案 2026 的 4 条目标均为 constraint_type = 'GE'、horizon_month = 24。

④ 指标评分（FR-11）

SELECT d.kpi_code, d.kpi_name, v.current_value, v.score, s.segment_desc FROM prcp_kpi_definition d LEFT JOIN prcp_kpi_value v ON v.kpi_id = d.id AND v.data_date = :bdd AND v.is_deleted = 0 LEFT JOIN prcp_kpi_score_rule r ON r.kpi_id = d.id AND r.is_deleted = 0 LEFT JOIN prcp_kpi_score_segment s ON s.rule_id = r.id AND s.is_deleted = 0 AND (s.min_value IS NULL OR v.current_value >= s.min_value) AND (s.max_value IS NULL OR v.current_value < s.max_value) WHERE d.is_deleted = 0 AND d.kpi_code LIKE 'REG_%'

⑤ 账户册树（导出用）

SELECT node_code, node_name, node_level, path, id, parent_id, sort_order FROM prcp_coa_node WHERE scheme_id = :sid AND is_deleted = 0 ORDER BY node_level, sort_order, node_code

命中索引：uk_scheme_code(scheme_id, node_code)。 parent_id 用于构建 children 索引（roll-up），path 用于大类分类与末级推断。

6.2 roll-up 上卷（父节点汇总）

// 末级节点：直接取自身预测余额 for nc in vals: if _is_leaf_of(nc): rolled[nc] = list(vals[nc]) // 父节点：递归求子树末级之和（自底向上） def _rollup(nc, depth=0): if nc in rolled: return rolled[nc] kids = children_of[node_id_by_code[nc]] if not kids: rolled[nc] = [0.0]*N; return rolled[nc] acc = [0.0]*N for k in kids: kv = _rollup(k, depth+1) for i in range(N): acc[i] += kv[i] rolled[nc] = acc return acc
关键：只采信末级节点的自身值。父节点一律由子树上卷得出， 因此不存在父子重复计算；各层级互不重叠，末级合计 = 账户册总额。

6.3 完成率与达标判定

约束类型完成率 达标判定说明
GE（≥）实际 / 目标 × 100实际 ≥ 目标当前方案全部目标均为 GE
LE（≤）目标 / 实际 × 100实际 ≤ 目标实际越小越接近目标
EQ（=）(1 − |实际−目标| / |目标|) × 100|实际−目标| < 1e-9
量纲保护（必须）：当 |实际/目标| 落在 [1e-3, 1e3] 之外时， 判定为量纲不可比，完成率返回 null，前端显示「-」。
实例：REG_EVE 目标为 -500000000（-5 亿，单位元）， 而实际值 ΔEVE 为 8.05（%），直接相除得 -0.0016%，看似精确实则荒谬。

6.4 KPI 聚合口径

KPI计算式说明
资产/负债/权益/表外余额 SUM(余额)，仅 _classify = 目标大类 且 _is_leaf 的节点 末级口径，避免父节点重复
贷款加权平均利率 Σ(余额 × 加权利率) / Σ(余额)，节点前缀 S01010101~05 取境内各项人民币贷款的 L4 子节点，不含 L3 父节点
5 指标均值 AVG(有值节点的 current_value) 取 prcp_metric_coefficient，无值节点不参与

编号问题等级说明与建议
