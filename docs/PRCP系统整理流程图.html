组合反算为主线 业务人员视角

0.1 主线一句话

业务人员在组合反算创建反算方案并选定计量模型（算法）、账户册方案、数据日期； 系统据此定位底层测算数据，把账户册拆成非模型训练节点（先走新业务模拟）与模型训练节点（后走计量模型）， 两者合并成完整业务表，再按指标计量逻辑算指标值、做指标评分，最终输出反算结果。

0.3 关键分流：模型训练节点 vs 非模型训练节点

分流开关就在 prcp_sim_node_config.is_model_calc（1 = 模型测算，2 = 非模型测算）：

节点类别is_model_calc 未来业务量来源特点
非模型训练节点2 新业务模拟（sim_result） 有明确业务规则（增长/节奏/期限），用配置推演即可，无需机器学习
模型训练节点1 计量模型（三类算法） 业务量受多因子影响、难以用规则表达，需要算法学习历史规律
为什么要分两批处理：非模型节点先算，是因为它的模拟结果要作为模型节点的 边界条件与约束输入（模型节点不能反推出已经由业务规则确定的部分）； 两批结果最后才合并成完整业务表。

0.4 完整业务表 → 指标计量 → 指标评分

① 完整业务表　　全账户册 × 24 月 × (current_value, adjusted_value, delta_value)
来源：非模型节点（模拟结果）∪ 模型节点（算法结果）

② 指标值计量　　按模型关联的指标方案逐项求值
type=1 → 公式引擎 evaluate(formula, ctx)
type=2 → 函数执行器 run_function_kpi(...)
ctx 注入同方案其他指标的该期值

③ 指标评分　　　区间命中 → 段内插值 → score
PIECEWISE：score_min + (x−min)/(max−min) × (score−score_min)
LINEAR　：锚点间线性插值 + 端点 clamp

④ 目标达成校验　按 prcp_reverse_target 的约束类型（GE/LE/EQ）逐条比对
不达成的目标 → 提示需调整模型或放宽约束

1.1 平台定位

PRCP（Portfolio Resource Coordination Platform）是面向银行资产负债管理（ALM）与 价值管理（VM）的一体化计量决策平台。核心能力：

  • 建账 —— 账户册（CoA）定义资产负债科目树与基准日余额
  • 算指标 —— 公式/函数双引擎计算监管与经营指标，并打分
  • 做预测 —— 新业务模拟推演未来 5 年余额与期限结构
  • 反推解 —— 组合反算求解满足 KPI 约束的最优资产负债路径
  • 做情景 —— ESG 场景工厂生成经济情景与收益率曲线

5.5 评分算法 · 两种模式

算法段语义 计算式说明
PIECEWISE
分段		[min, max) 区间 score_min + (x−min)/(max−min) × (score−score_min) score_min 为空 → 阶梯评分（取该段 score）；非空且区间宽 > 0 → 段内插值
LINEAR
线性		(x, score) 锚点对 y1 + (x−x1)/(x2−x1) × (y2−y1) 锚点按 x 升序插值；超出范围按端点 clamp
