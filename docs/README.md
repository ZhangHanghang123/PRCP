## 关键决策

1. **业务定位升级**：v1 的"资金组算"过窄，v2 升级为"经营计划与资产负债预测平台"
2. **树形存储**：用物化路径 + 父 ID 双策略，查询快且能拖拽
3. **公式引擎**：自研纯 Python（不依赖外部包），支持四则 + SUM/AVG/MAX/MIN + ABS/ROUND/IF
4. **函数指标**：v2.0+ 引入 kpi_function_runner（白名单 + importlib 动态加载 + ctx dict + mtime 热重载）
5. **算法适配层**：用户后续提供的算法只替换 `services/` 下的实现，前后端不改
6. **字典国际化**：v2.5+ 引入 sys_dict 单表 + DictProvider Context，避免硬编码中文
7. **软删除 + UNIQUE 复活**：create_version / create_param / apply-template 通用模式
8. **64 桶期限桶**：v2.2+ 1 年内按月 + m13-m60 补全 5 年 + 长端 y10/y15/y20/y30
9. **审计日志**：所有写入操作必审计，符合金融合规要求
10. **版本管理**：指标 + 模型 + 反算都按版本归档，可对比、可回溯
11. **Dashboard = 驾驶舱**：v3.0+ 把首页升级为"组合反算驾驶舱"，所有关键指标集中展示
12. **指标计量系数**：v2.9+ 引入 prcp_metric_coefficient 表，挂账户册节点 × 5 监管指标 × 数据日期
13. **反算联动**：v3.0+ 反算方案 × Run × 月份 联动展示 prcp_metric_coefficient 数据
