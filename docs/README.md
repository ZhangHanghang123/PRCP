## 7 大业务模块

1. **账户册维护** — 账户册方案 + 结构（树形）
2. **报表表项管理** — 6 类报表 + 表项结构（树形）
3. **数据维护** — 6 类指标数据 + 资产负债表（24 月现金流）
4. **指标管理** — 指标定义（含公式）+ 指标维护（按版本）
5. **模型管理** — 参数版本 + 参数 + 训练任务
6. **组合反算** — 反算方案 + 反算结果（未来 20 年）
7. **系统管理** — 用户 / 角色 / 字典

## 业务链路

```
账户册 ─→ 报表 ─→ 数据 ─→ 指标 ─→ 模型 ─→ 反算
   基础建模  模板   录入   公式    训练    预测
```

## 关键决策

1. **业务定位升级**：v1 的"资金组算"过窄，v2 升级为"经营计划与资产负债预测平台"
2. **树形存储**：用物化路径 + 父 ID 双策略，查询快且能拖拽
3. **公式引擎**：自研纯 Python（不依赖外部包），支持四则 + SUM/AVG/MAX/MIN + ABS/ROUND/IF
4. **算法适配层**：用户后续提供的算法只替换 `app/algorithms/v1.py`，前后端不改
5. **审计日志**：所有写入操作必审计，符合金融合规要求
6. **版本管理**：指标 + 模型 + 反算都按版本归档，可对比、可回溯
