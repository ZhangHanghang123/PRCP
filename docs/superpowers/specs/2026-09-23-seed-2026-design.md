## 一、设计目标

为组合反算 · 结果驾驶舱、指标计量系数维护、反算指标结果表**三个模块**准备一版完整的演示数据，**所有数据均能查询到**。

| 维度 | 设计 |
|------|------|
| **方案** | `2026`（rev_id=5, coa_scheme_id=6 = ZXCOA_V1） |
| **节点** | 40 个（来自 ZXCOA_V1） |
| **月份** | 24 个月（M1~M24，data_date=2026-01-01 ~ 2027-12-01） |
| **指标** | 5 个（ROE / CET1 / LCR / NSFR / ΔEVE） |
| **新 Run** | run_id=7（SUCCESS） |

## 三、字段设计

### 3.1 prcp_data_reverse（每行字段）

```
id              VARCHAR(64)   -- "2026_7_<node_code>_M<i>"
scheme_code     VARCHAR(64)   -- "2026"
run_id          INT           -- 7
coa_scheme_id   INT           -- 6
data_date       DATE          -- 2026-01-01 ... 2027-12-01
date_offset     INT           -- 1..24
offset_unit     VARCHAR(4)    -- "M"
coa_node_id     INT           -- from prcp_coa_node
node_code       VARCHAR(64)   -- "ZX_A001"..."ZX_A022"...
node_name       VARCHAR(128)
node_level      INT           -- 1..5
current_balance DECIMAL(20,2) -- 节点金额（按节点类型分布）
avg_balance     DECIMAL(20,2) -- 同上
risk_weight      DECIMAL(8,4)   -- 默认 1.0
weighted_rate   DECIMAL(8,4)   -- 默认 3.5%
interest_amount DECIMAL(20,2)  -- current_balance * 0.035 / 12
orig_m1..m60    DECIMAL(20,2)  -- 原始期限分布
orig_y10/y15/y20/y30 DECIMAL(20,2)
rem_m1..m60     DECIMAL(20,2)  -- 剩余期限分布
rem_y10/y15/y20/y30 DECIMAL(20,2)
category        VARCHAR(32)   -- "OTHER"（seed 脚本默认；前端按 node_code 前缀再分类）
```

```
id                  VARCHAR(128)  -- "{coa_scheme_code}_{node_code}_{metric_code}_{YYYYMMDD}"

node_code           VARCHAR(64)

current_value       DECIMAL(20,6) -- 关键展示列
y1_value ~ y5_value DECIMAL(20,6) -- 备用
unit                VARCHAR(16)   -- PERCENT/ABSOLUTE
description         VARCHAR(255)
status              VARCHAR(16)   -- ACTIVE
```

## 四、指标值演算法（让数据有"故事性"）

| 指标 | 基础值 | 月度演变 | 单位 |
|------|--------|----------|------|
| ROE | 13.84 | +0.046/月(M_i) | % |
| CET1 | 11.03 | +0.025/月(M_i) | % |
| LCR | 150.20 | +0.124/月(M_i) | % |
| NSFR | 108.05 | +0.046/月(M_i) | % |
| ΔEVE | -2.55 | -0.083/月(M_i) | 百万元 |

```
M1 (2026-01-01): ROE=13.84 CET1=11.03 LCR=150.20 NSFR=108.05 ΔEVE=-2.55
M12 (2026-12-01): ROE=14.39 CET1=11.33 LCR=151.69 NSFR=108.60 ΔEVE=-3.55
M24 (2027-12-01): ROE=14.94 CET1=11.63 LCR=153.18 NSFR=109.39 ΔEVE=-4.55
```

- **ROE/CET1/LCR/NSFR 递增**：模拟机构经营改善
- **ΔEVE 负向加深**：模拟利率风险随时间累积

## 八、Bug 修复（脚本开发期间）

1. **cols 与 vals 命名不一致**：vals 用 `sc/rid/nid`，cols 用 `scheme_code/run_id/node_id` → SQLAlchemy 找不到绑定参数
2. **orig_buckets 桶数不足**：只填了 16 桶（m1~m12 + y10/y15/y20/y30），cols 是 64 桶 → 补全 m13~m60
