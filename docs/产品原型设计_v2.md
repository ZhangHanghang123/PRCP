# PRCP 产品原型设计 v2.0 — 经营计划与资产负债预测平台

> 基于 `docs/产品功能菜单.xlsx` 重新梳理。原 v1.0（资金组算）定位过窄，本版定位升级为：
> **PRCP（Portfolio Resource Coordination & Planning）= 经营计划与资产负债预测平台**
>
> 业务链路：**账户册建模 → 报表模板 → 数据维护 → 指标体系 → 模型训练 → 组合反算**

---

```

```

> 7 大模块 = 6 大业务链路 + 系统管理

## 3. 模块详解

### 3.1 账户册维护

**业务定位**：定义银行的账户层级结构（COA = Chart of Accounts），是所有数据维护和指标计算的基础。

#### 3.1.1 账户册方案定义

**页面布局**：顶部筛选 + 列表 + 新增/编辑抽屉

```
┌────────────────────────────────────────────────────────────┐
│ [方案编码▼] [状态▼] [搜索...] [+ 新增方案] [导入] [导出] │
├────────────────────────────────────────────────────────────┤
│ ☐ │ 方案编码 │ 方案名称   │ 状态 │ 节点数 │ 创建人 │ 操作 │
│ ☐ │ BS_2026  │ 资负表方案 │ ACTIVE│  247  │ admin │ 编/删 │
│ ☐ │ PL_2026  │ 损益表方案 │ ACTIVE│  128  │ admin │ 编/删 │
└────────────────────────────────────────────────────────────┘
```

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 方案编码 | VARCHAR(32) UNIQUE | 如 `BS_2026` |
| 方案名称 | VARCHAR(64) | 必填 |
| 状态 | ENUM('ACTIVE','INACTIVE') | 默认 ACTIVE |
| 描述 | TEXT | 选填 |
| 创建人/创建时间 | - | 自动 |

**操作**：新增、删除（软删）、修改、查询（多条件）、导入 Excel、导出 Excel

#### 3.1.2 账户册结构定义

**页面布局**：**左右栏**（xlsx 明确要求）

```
┌──────────────────────┬─────────────────────────────────────┐
│ 【树形结构】          │ 【账户册详情】                        │
│                      │                                      │
│ ▼ 资产 (1000)         │ 节点编码：[11001]                     │
│   ▼ 现金 (1100)       │ 节点名称：[现金及存放中央银行款项]    │
│     ▶ 库存现金 (11001)│ 父节点：[现金 (1100)]                │
│     ▶ 央行存款 (11002)│ 节点层级：[3]                       │
│   ▶ 贷款 (1200)       │ 节点类型：[ASSET]                   │
│ ▶ 负债 (2000)         │ 排序：[10]                          │
│ ▶ 权益 (3000)         │ 状态：[ACTIVE▼]                     │
│                      │                                      │
│ [+ 新增节点] [编辑]   │ [保存] [取消]                        │
└──────────────────────┴─────────────────────────────────────┘
```

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 节点编码 | VARCHAR(32) | 必填，方案内唯一 |
| 节点名称 | VARCHAR(64) | 必填 |
| 父节点 | FK → 自身 | 树形关系 |
| 节点层级 | INT | 自动计算 |
| 节点类型 | ENUM | ASSET/LIABILITY/EQUITY/INCOME/EXPENSE |
| 排序 | INT | 同级排序 |
| 状态 | ENUM | ACTIVE/INACTIVE |

**操作**：树形新增（"+ 新增"按钮）、编辑、删除（软删）、拖拽排序、批量导入

### 3.2 报表表项管理

#### 3.2.1 报表定义管理

**页面布局**：列表 + 新增对话框

```
┌────────────────────────────────────────────────────────────────┐
│ [+ 新增报表] [导入] [导出]                                      │
├────────────────────────────────────────────────────────────────┤
│ ☐ │ 报表编码   │ 报表名称   │ 类型        │ 关联账户册 │ 状态 │
│ ☐ │ RPT_BS     │ 资负表     │ BALANCE     │ BS_2026   │ ACTIVE│
│ ☐ │ RPT_PL     │ 损益表     │ INCOME      │ PL_2026   │ ACTIVE│
│ ☐ │ RPT_CF     │ 现金流量表 │ CASHFLOW    │ CF_2026   │ ACTIVE│
│ ☐ │ RPT_KPI    │ 关键指标   │ INDICATOR   │ KPI_2026  │ ACTIVE│
│ ☐ │ RPT_RWA    │ RWA 报表   │ RISK        │ BS_2026   │ ACTIVE│
│ ☐ │ RPT_LIQ    │ 流动性报表 │ LIQUIDITY   │ BS_2026   │ ACTIVE│
└────────────────────────────────────────────────────────────────┘
```

**6 类报表类型**（xlsx 明确要求 6 类）：
1. **BALANCE** — 资产负债表
2. **INCOME** — 损益表
3. **CASHFLOW** — 现金流量表
4. **INDICATOR** — 关键指标报表
5. **RISK** — 风险加权资产报表
6. **LIQUIDITY** — 流动性报表

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 报表编码 | VARCHAR(32) UNIQUE | 如 `RPT_BS` |
| 报表名称 | VARCHAR(64) | 必填 |
| 报表类型 | ENUM(6) | 上述 6 类之一 |
| 关联账户册方案 | FK → 账户册方案 | 必填 |
| 描述 | TEXT | |
| 状态 | ENUM | ACTIVE/INACTIVE |

#### 3.2.2 报表结构定义

**页面布局**：**左右栏 + 树形表项**

```
┌──────────────────────┬─────────────────────────────────────┐
│ 【表项树形结构】      │ │ 【表项详情】                        │
│                      │ │                                     │
│ ▼ 资产 (一级)        │ │ 表项编码：[BS_ASSET_TOTAL]          │
│   ▶ 流动资产         │ │ 表项名称：[资产总计]                │
│   ▶ 固定资产         │ │ 父表项：[无]                       │
│ ▶ 负债 (一级)        │ │ 表项层级：[1]                       │
│ ▶ 权益 (一级)        │ │ 数据类型：[DECIMAL]                 │
│                      │ │ 计算公式：[SUM(...)]                │
│ [+ 新增] [✎ 编辑] [🗑]│ │ 关联账户册节点：[多选]              │
│                      │ │ 排序：[10]                          │
│                      │ │ [保存] [取消]                        │
└──────────────────────┴─────────────────────────────────────┘
```

**字段**：
| 字段 | 类型 | 说明 |
|------|------|------|
| 表项编码 | VARCHAR(32) | 报表内唯一 |
| 表项名称 | VARCHAR(64) | 必填 |
| 父表项 | FK → 自身 | 树形 |
| 报表 | FK → 报表定义 | 必填 |
| 表项层级 | INT | |
| 数据类型 | ENUM | DECIMAL/INT/TEXT |
| 计算公式 | TEXT | 支持 SUM/AVG/MAX 等 |
| 关联账户册节点 | JSON | 多选节点 ID 列表 |
| 排序 | INT | |
| 状态 | ENUM | |

**特殊功能（"增三改"）**：xlsx 提到"树形结构上有增三改功能"——理解为 增/删/改/排序/复制/批量粘贴 三类操作的增强版。

## 4. 全局功能与交互

### 4.1 通用组件

| 组件 | 用途 | 出现页 |
|------|------|--------|
| **左右栏树形** | 父子层级数据 | 账户册结构、报表结构 |
| **分子分母多选器** | 选择账户册节点 | 数据维护 6 类指标 |
| **公式编辑器** | 表达式输入 + 校验 | 指标定义 |
| **导入向导** | Excel 模板下载 + 校验 + 上传 | 所有 CRUD 页 |
| **导出向导** | 列选择 + 格式（Excel/PDF/CSV） | 所有列表页 |
| **版本对比器** | 左右双栏对比两版本 | 模型参数、指标维护 |

### 4.2 权限模型

```
用户 (sys_user) ─1:N─→ 角色 (sys_role) ─N:N─→ 权限 (sys_permission)
                                       │
                                       └──→ 菜单（路由 key）
                                       └──→ 数据（按报表/版本控制读写）
```

### 4.3 审计日志

所有"数据维护"、"模型训练"、"组合反算"的关键操作都需审计：
- 操作人 / 操作时间 / 操作类型 / 操作对象 / 前后值 JSON

## 6. 端到端业务场景示例**

### 场景：年度经营计划编制

```
1. 维护账户册
   └─ 在"账户册结构"中新增"专项再贷款"账户（11099）

2. 录入资产负债表
   └─ 在"资产负债表"录入 2025-12 数据，含未来 24 个月现金流缺口

3. 维护指标定义
   └─ 新建指标"KPI_NIM_NEW = 利息净收入/生息资产平均余额"

4. 选择模型参数版本 V1.0，触发训练
   └─ "模型训练"页点击开始训练，10 分钟后完成

5. 创建反算方案 RC_2025Q4
   └─ 加载 KPI_CAR=14%, KPI_NIM=1.85%, KPI_LCR=120%
   └─ 选择 V1.0 模型版本，点击反算

6. 查看反算结果
   └─ 未来 20 年资负表 + 指标曲线
   └─ 导出 Excel 给经营计划会议
```
