# PRCP 利率管理模块设计

## 一、业务概述

### 1.1 业务定位

利率管理模块（Rate Management）是 PRCP 平台的**利率中枢**，提供：
- 多种类型收益率曲线的**录入、维护、查询**（国债 / 政策性金融债 / 同业存单 / LPR / FTP 等）
- **历史曲线对比**（同一曲线不同日期 / 不同曲线同一日期）
- 为其他模块（基础数据表加权平均利率、KPI 指标 NIM/FTP、模型管理贴现率）提供**利率查询服务**

### 1.2 核心实体关系

```
prcp_rate_curve (曲线方案) 1 ─── N prcp_rate_point (曲线明细)
   ↑ 曲线编码                  ↑ 某曲线 + 某数据日期 + 13 个期限利率
   │ (主键)                    │
   └── 曲线类型：国债/政金/同业存单/LPR/FTP
       币种：CNY / USD
       状态：ACTIVE / HISTORY
```

## 三、数据库设计

### 3.1 表 1：`prcp_rate_curve` 曲线方案

```sql
CREATE TABLE prcp_rate_curve (
  id                BIGINT AUTO_INCREMENT PRIMARY KEY,
  curve_code        VARCHAR(32) NOT NULL COMMENT '曲线编码（业务唯一）',
  curve_name        VARCHAR(64) NOT NULL COMMENT '曲线名称',
  curve_type        VARCHAR(16) NOT NULL COMMENT '曲线类型（SOVEREIGN/POLICY/CD/LPR/FTP/CUSTOM）',
  ccy               VARCHAR(8)  DEFAULT 'CNY' COMMENT '币种',
  data_source       VARCHAR(32) COMMENT '数据源（WIND/CHOICE/中债/手工录入）',
  description       TEXT COMMENT '描述',
  status            VARCHAR(8)  DEFAULT 'ACTIVE' COMMENT 'ACTIVE/HISTORY',
  is_deleted        TINYINT(1) DEFAULT 0,
  created_by        BIGINT,
  updated_by        BIGINT,
  created_at        DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_curve_code (curve_code, is_deleted),
  INDEX idx_type (curve_type)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='利率曲线方案';
```

### 3.2 表 2：`prcp_rate_point` 曲线明细（13 个期限点用列）

```sql
CREATE TABLE prcp_rate_point (
  id                BIGINT AUTO_INCREMENT PRIMARY KEY,
  curve_code        VARCHAR(32) NOT NULL COMMENT '冗余曲线编码（便于查询）',
  curve_id          BIGINT NOT NULL COMMENT '关联 prcp_rate_curve.id',
  data_date         DATE NOT NULL COMMENT '数据日期',
  
  -- 13 个期限点的利率（年化%，保留 4 位小数）—— 用列存储
  rate_d1           DECIMAL(8,4) COMMENT '1日利率',
  rate_d7           DECIMAL(8,4) COMMENT '7日利率',
  rate_m1           DECIMAL(8,4) COMMENT '1M（1月）利率',
  rate_m3           DECIMAL(8,4) COMMENT '3M（3月）利率',
  rate_m6           DECIMAL(8,4) COMMENT '6M（6月）利率',
  rate_y1           DECIMAL(8,4) COMMENT '1Y（1年）利率',
  rate_y2           DECIMAL(8,4) COMMENT '2Y（2年）利率',
  rate_y3           DECIMAL(8,4) COMMENT '3Y（3年）利率',
  rate_y5           DECIMAL(8,4) COMMENT '5Y（5年）利率',
  rate_y10          DECIMAL(8,4) COMMENT '10Y（10年）利率',
  rate_y15          DECIMAL(8,4) COMMENT '15Y（15年）利率',
  rate_y20          DECIMAL(8,4) COMMENT '20Y（20年）利率',
  rate_y30          DECIMAL(8,4) COMMENT '30Y（30年）利率',
  
  -- 度量列
  curve_shift_bps   DECIMAL(10,4) COMMENT '当日曲线平移（基点 BP）',
  curve_slope       DECIMAL(10,6) COMMENT '斜率（10Y - 1Y）',
  is_deleted        TINYINT(1) DEFAULT 0,
  created_by        BIGINT,
  updated_by        BIGINT,
  created_at        DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at        DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  UNIQUE KEY uk_curve_date (curve_id, data_date, is_deleted),
  INDEX idx_curve_code (curve_code),
  INDEX idx_date (data_date)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='利率曲线明细（13 个期限点用列）';
```

### 3.3 设计要点

1. **13 个期限点用列存储**（不是行）—— 符合用户要求，便于横向对比
2. **每条曲线 × 每个数据日期** = 一行（不是 13 行）
3. **`curve_code` 冗余**：明细表存 `curve_id` + `curve_code`，JOIN 时无需再查方案表
4. **度量列**：`curve_shift_bps`（BP 平移）和 `curve_slope`（斜率）作为常用 KPI 自动计算

## 七、API 详细定义

### 7.1 曲线方案

```
GET /api/rate/curves
  → {"items": [{"id", "curve_code", "curve_name", "curve_type", "ccy", "data_source", "description", "status", "point_count", "created_at"}]}

POST /api/rate/curves
  body: {"curve_code", "curve_name", "curve_type", "ccy", "data_source", "description"}
  → {"id"}

PUT /api/rate/curves/{id}
  body: {"curve_name", "curve_type", "ccy", "data_source", "description", "status"}
  → {"ok": true}

DELETE /api/rate/curves/{id}
  → {"ok": true}
  副作用：软删 prcp_rate_point 中所有 is_deleted=0 的明细
```

### 7.2 曲线明细

```
GET /api/rate/points?curve_code=X&date_from=YYYY-MM-DD&date_to=YYYY-MM-DD&limit=500
  → {"items": [{"id", "curve_code", "data_date", "rate_d1", ..., "rate_y30", "curve_shift_bps", "curve_slope", "created_at"}]}

POST /api/rate/points
  body: {"curve_code", "data_date", "rate_d1", ..., "rate_y30"}
  → {"id", "curve_shift_bps", "curve_slope"}
  副作用：自动计算 BP 平移（与上一日 10Y 利率差）和斜率（10Y - 1Y）

DELETE /api/rate/points/{id} → {"ok": true}

GET /api/rate/points/by-date?data_date=YYYY-MM-DD
  → {"items": [{"curve_code", "curve_name", "data_date", "rate_d1", ..., "rate_y30"}]}
  用途：横向对比所有曲线在某日的利率

GET /api/rate/points/compare?curve_code1=X&curve_code2=Y&date_from=...&date_to=...
  → 用于前端画对比折线图
```

### 7.3 Excel

```
GET /api/rate/export-xlsx?curve_code=X&date_from=...&date_to=...
  → Excel 二进制（15 列：曲线编码 + 名称 + 数据日期 + 13 个期限 + BP + 斜率 + 备注）

POST /api/rate/import-xlsx
  body: multipart/form-data，file=模板 Excel
  → {"inserted": N, "updated": M, "skipped": K, "errors": [...]}
```
