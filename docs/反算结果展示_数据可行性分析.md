# 反算结果展示原型 — 数据可行性比对报告

> 文档版本: v1.0 | 日期: 2026-09-18 17:27 | 分析对象: `反算结果展示_页面原型.html`
> 比对对象: PRCP 当前系统的实际数据（DB: prcp_db）

---

## 一、TL;DR

| 维度 | 结论 |
|------|------|
| **静态 mock → 实时数据** | 仅 **~25%** 可直接落地；**~40%** 需要补数据/扩展字段；**~35%** 需要新增模块（情景框架 / 规则引擎 / LLM 建议） |
| **核心阻塞** | ① weighted_rate/risk_weight 全为 0 → NII/NIM/CAR/WAC 无法真实计算 ② prcp_data_balance 24 月 gap 全为 0 → 期限缺口热力图无数据 ③ 系统仅 1 个方案单次反算，无多情景框架 |
| **可立即落地的部分** | 时间轴 / 24 月节点预测值 / 简单 TOP10 缺口排序 / 元信息(基础日/账户数/数据量) |
| **建议路径** | 先做 "数据补全" → 再做 "情景框架" → 最后接 "LLM 建议" |

## 三、原型元素逐项可行性

### 3.1 顶部 6 大 KPI 卡

| KPI | 原型数值 | 数据源需求 | 系统能提供？ | 阻塞原因 |
|-----|---------|-----------|-------------|----------|
| **NIM 24M** | 2.18% ↑12BP | 月度 NIM 序列 + 24 月累计 | ⚠️ **部分** | `prcp_reverse_run.metrics.kpi_actual.KPI_NIM.actual=2.5375` 是总值；无 24 月 NIM 序列（需加权 rate） |
| **NII 24M** | 187.6 亿 ↑8.3% | 月度 NII 序列 | ❌ **无** | `interest_amount` 全为 0，无 monthly NII 序列 |
| **GAP** | +126.4 亿 ↓32.7% | 24 月累计期限缺口 | ❌ **无** | `prcp_data_balance.m1_gap~m24_gap` 全 0；`prcp_data_reverse.rem_*` 几乎空 |
| **LMR** | 128.5% ↑5.2pct | ASF/RSF 比率 | ❌ **无** | `asf_rsf` 字段全 NULL；无 LMR 计算引擎 |
| **CAR** | 14.32% ↑0.45pct | 风险加权/资本 | ❌ **无** | `risk_weight` 全 0；无 CAR 字段；无资本充足率计算 |
| **WAC** | 2.84% ↑8BP | Σ(balance×rate)/Σ(balance) | ❌ **无** | `weighted_rate` 全 0 |
| **6 张 mini sparkline** | 各 24 点 | 同上 KPI 的 monthly 序列 | ❌ **无** | 6 个 KPI 本身都没 monthly 序列 |

### 3.2 第一行：NII 现金流预测 + 期限缺口热力图

| 元素 | 所需数据 | 系统能提供？ | 阻塞原因 |
|------|---------|-------------|----------|
| **月度 NII 中枢** | 24 月 monthly NII | ❌ | `interest_amount=0` |
| **95% 置信上界 / 下界** | 多次反算样本或 bootstrap | ❌ | 当前为确定性单次反算，需扩展为 Monte Carlo |
| **累计 NII** | Σ(monthly NII) | ❌ | 同上 |
| **热力图 20 节点 × 13 期限** | 节点×期限二维缺口 | ❌ | 节点 19 vs 需求 20；rem_y30=0；rem_y5 也无数据 |
| **热力图标签** | "对公活期/对公定期/零售活期..." 等业务条线 | ❌ | COA 节点是 L1-L5 抽象层级（ZX_A001/ZX_L003 等编码），无"对公/零售"等业务分类 |

### 3.3 第二行：雷达图 + 瀑布图 + 期限结构

| 元素 | 所需数据 | 系统能提供？ | 阻塞原因 |
|------|---------|-------------|----------|
| **多情景雷达 (4 情景 × 6 维)** | BASE/OPT/PESS/STRESS 4 方案 | ❌ | 系统仅支持单方案；无情景框架（schema 中无 `scenario` 字段） |
| **业务条线瀑布 (6 条线)** | 按 业务条线 汇总 NII | ❌ | 无 `business_line` 字段；无 业务条线 字典 |
| **期限结构堆叠面积 (5 段 × 24 月)** | 5 期限段占比的 24 月演变 | ❌ | 期限桶数据空；无 "5 段" 业务归类（如 ≤3M / 3-12M / 1-5Y / 5-10Y / >10Y） |

### 3.4 第三行：TOP10 缺口 + 风险预警 + AI 建议

| 元素 | 所需数据 | 系统能提供？ | 阻塞原因 |
|------|---------|-------------|----------|
| **TOP10 账户缺口** | 账户级 ± 缺口排序 | ⚠️ **部分** | rem_m1/m3/y1/y10 有部分值，可做 TOP10；但 y30 空所以缺长期数据 |
| **风险预警 8 项** | 规则引擎（LMR<100%/GAP>+25亿/NIM偏离目标） | ❌ | 无 `prcp_alert_rule` 规则表；无 `prcp_alert` 预警实例表 |
| **AI 优化建议 5 项** | LLM 调用 DeepSeek | ⚠️ **可接** | 已配置 DeepSeek API；需写 prompt 模板 + 上送当前数据快照 |

### 3.5 第四行：多情景对比表

| 元素 | 所需数据 | 系统能提供？ | 阻塞原因 |
|------|---------|-------------|----------|
| **4 情景 × 7 指标对比** | 4 方案同时反算 | ❌ | 单方案框架；需扩展 `prcp_reverse_scheme.scenario` 字段 + 调度并行执行 |
| **NPL 不良率** | 1.32% | ❌ | 完全不在当前模型范围；无 NPL 数据 |
| **达成状态 (✓/⚠️/✗)** | 实际值 vs 目标 | ⚠️ **部分** | NIM 可对比；LMR/CAR/GAP/WAC 无数据 |

### 3.6 时间轴

| 元素 | 所需数据 | 系统能提供？ | 备注 |
|------|---------|-------------|------|
| **24 月时间轴 + 滑块** | 按 month 切片数据 | ✅ **完全可** | `prcp_reverse_result.predict_month` 1-24 + `predict_date` 已规范存储 |
| **当前月份快照** | 某月累计 NII/KPI | ⚠️ **部分** | NII 无；NIM 可从 run.metrics 但仅总值非序列 |

## 五、需要补数据/扩展字段（中等成本）

### 5.1 补 weighted_rate 与 risk_weight（最关键）

```sql
-- 1) 利率：从 CURV 模块的收益率曲线 + 账户册分类映射
--    CURV 已有：prcp_rate_curve / prcp_rate_point（已上线）
--    需要：COA 节点 + 期限段 → 利率档位 映射表
ALTER TABLE prcp_coa_node ADD COLUMN rate_term_ref VARCHAR(32);   -- 利率期限引用
ALTER TABLE prcp_data_reverse MODIFY weighted_rate DECIMAL(10,6); -- 已有

-- 2) 风险权重：从 巴塞尔资本协议权重表
CREATE TABLE prcp_risk_weight_table (
  asset_class VARCHAR(32), risk_weight DECIMAL(5,2), ref_doc VARCHAR(255)
);
INSERT INTO prcp_risk_weight_table VALUES
  ('对公一般贷款', 100.00, '巴Ⅲ标准'),
  ('零售贷款', 75.00, '巴Ⅲ标准'),
  ('国债', 0.00, '零风险'),
  ('地方政府债', 20.00, '巴Ⅲ标准'),
  ...
```

### 5.2 补 24 月现金流缺口（prcp_data_balance.m1-m24_gap）

```sql
-- 优先级 P1：从基础数据表 prcp_data_basic 的 date_offset 派生
--    prcp_data_basic 已有 scheme_id × data_date × coa_node × date_offset(0..23) × balance
SELECT coa_node_id, date_offset, SUM(balance) AS gap
FROM prcp_data_basic WHERE scheme_id=6 AND data_date='2025-12-31' AND date_offset BETWEEN 1 AND 24
GROUP BY coa_node_id, date_offset;
```

### 5.4 加多情景字段

ALTER TABLE prcp_reverse_scheme

## 六、需要新增模块（高成本）

### 6.1 风险预警规则引擎

```
backend/app/services/risk_alert_engine.py

规则集（示例）：
- GAP_OVER_LIMIT     : abs(累计 GAP) > 25 亿  → HIGH
- NIM_BELOW_TARGET   : NIM<目标值-20BP         → HIGH
- LMR_BREACH         : LMR<100%               → HIGH
- CONCENTRATION_LIMIT: 单一期限段占比 > 50%   → MED
- WAC_UP             : WAC 上行 > 10BP        → MED

输出：prcp_alert 表 (run_id, rule_code, severity, title, desc, metric_value)
```

### 6.2 多情景并行调度器

```
backend/app/services/scenario_runner.py

- 接收 4 个 scenario 参数 + 利率冲击 / 流失率
- 并行启动 4 次反算
- 汇总 4 个 result 到 prcp_scenario_compare 表
- 返回 { BASE: {...}, OPT: {...}, PESS: {...}, STRESS: {...} }
```

### 6.3 AI 优化建议（LLM 集成）

```
backend/app/services/llm_suggester.py

- 输入：当前 run 的 metrics + prcp_data_reverse 24月快照 + 风险预警列表
- Prompt 模板：作为银行风险管理专家，给出 5 条优先级排序的优化建议，
                每条含：建议标题 / 描述 / 预期影响(NII+/LMR+/CAR+)
- 输出：5 条结构化建议
- 模型：DeepSeek-chat（已配置 API）
```

### 6.4 Monte Carlo 置信带计算

```
backend/app/services/ci_calculator.py

- 同一方案 N=100 次随机扰动（扰动：weighted_rate ±σ, balance ±σ）
- 每次跑反算
- 输出 monthly NII 的 P2.5/P50/P97.5
```

## 八、总结

**数据可行性结论**：

✅ **完全可做（25%）**：时间轴、24 月节点预测值、TOP10 缺口（基于已有桶）、元信息、NIM 单点
⚠️ **补数据后可做（40%）**：NII/GAP/LMR/WAC/CAR 5 个 KPI + 期限缺口热力图（需补 weighted_rate/gap/asf_rsf）
❌ **需新模块（35%）**：多情景框架、风险预警引擎、AI 建议（LLM）、业务条线瀑布、NPL 数据

**原型的 35% 元素需要新建模块而非"加工"**，建议按 Phase 1-5 路线分批实施。
