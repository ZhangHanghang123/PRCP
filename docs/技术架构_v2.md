
### 3.3 算法适配层

```python
# app/algorithms/base.py
from abc import ABC, abstractmethod

class BaseAlgorithm(ABC):
    """用户后续提供的算法基类"""

    @abstractmethod
    def fit(self, balance_data: dict, params: dict) -> dict:
        """训练：balance_data = 资产负债表历史，params = 参数版本值
        返回 model_meta（可序列化的模型描述）"""

    @abstractmethod
    def predict(self, balance_data: dict, params: dict, model_meta: dict) -> dict:
        """预测 / 反算：返回 20 年资负 + 指标结果"""

    @abstractmethod
    def serialize(self, model_meta: dict) -> str:
        """模型元数据 → JSON 字符串（存 DB）"""

    @abstractmethod
    def deserialize(self, raw: str) -> dict:
        """JSON 字符串 → 模型元数据"""

# 用户后续替换：
# app/algorithms/v1.py
class UserAlgorithmV1(BaseAlgorithm):
    def fit(self, balance_data, params): ...
    def predict(self, balance_data, params, model_meta): ...
```

**好处**：前端和数据库不变，只替换 `model_runner.py` 和 `reverse_runner.py` 中的算法调用即可接入。

## 4. 数据流

### 4.1 训练数据流

```
[6 类指标数据]   ─┐
[资产负债表 M24] ─┼──→ model_runner.fit()
[参数版本 V1.0] ──┘            │
                               ▼
                       model_meta (JSON)
                               │
                               ├──→ 存 prcp_model_train_task.model_meta
                               └──→ /data/models/{tid}/model.pkl（可选）
```

### 4.2 反算数据流

```
[反算方案 RC_001] ──→ reverse_runner.predict()
[资产负债表]            │
[参数版本]              │
[历史指标]              ▼
                    20 年反算结果 (JSON)
                               │
                               ├──→ 存 prcp_reverse_result.result_json
                               └──→ SSE 推送到前端 ECharts
```

### 4.3 公式计算数据流

```
[指标定义 公式:"SUM(BS_A001, BS_A002) / BS_L001"]  ─┐
[资产负债表 2025-12 数据]                          ─┼──→ formula_engine.calc()
[账户册节点关联]                                    ─┘            │
                                                              ▼
                                                       当前值: 14.32%
                                                              │
                                                              └──→ prcp_kpi_value
```

## 5. API 设计规范

### 5.1 RESTful 风格

```
GET    /prcp/api/{module}              # 列表（分页 + 过滤）
GET    /prcp/api/{module}/{id}         # 详情
POST   /prcp/api/{module}              # 新增
PUT    /prcp/api/{module}/{id}         # 修改
DELETE /prcp/api/{module}/{id}         # 软删
POST   /prcp/api/{module}/import       # Excel 导入
GET    /prcp/api/{module}/export       # 导出
```

### 5.2 特殊接口

| 接口 | 方法 | 用途 |
|------|------|------|
| `/coa/nodes/tree` | GET | 整棵账户册树 |
| `/coa/nodes/{id}/move` | POST | 拖拽移动 |
| `/rpt/items/tree` | GET | 整棵报表表项树 |
| `/rpt/items/{id}/formula-preview` | POST | 公式实时预览 |
| `/model/train/{id}/stream` | GET (SSE) | 训练进度推送 |
| `/reverse/{id}/stream` | GET (SSE) | 反算进度推送 |
| `/reverse/{id}/export` | GET | 导出反算结果 Excel |

### 5.3 统一响应格式

```json
{
  "code": 0,
  "message": "ok",
  "data": { ... },
  "timestamp": 1735891200
}
```

错误响应：
```json
{
  "code": 4001,
  "message": "账户册节点编码重复",
  "field": "node_code"
}
```

## 6. 性能与扩展

### 6.1 性能指标

| 接口 | P95 响应 | 备注 |
|------|---------|------|
| 列表查询（分页 20） | < 200ms | 走索引 |
| 树形查询 | < 300ms | 整棵树 ≤ 500 节点 |
| Excel 导入 1000 行 | < 5s | 批量插入 + 事务 |
| 公式计算（1 个指标） | < 50ms | 纯 Python |
| 模型训练（v2.3 接入后） | 取决于算法 | 异步任务 + SSE |

### 6.2 扩展点

| 维度 | 当前 | 扩展方式 |
|------|------|---------|
| 报表类型 | 6 类 | 加 ENUM + 加配置即可 |
| 指标公式 | 基础四则 + 函数 | formula_engine 加 plugin |
| 模型算法 | v1 placeholder | 替换 `app/algorithms/v1.py` |
| 反算算法 | v1 placeholder | 替换 `app/algorithms/v1.py` |
| 数据源 | 手工录入 | 加 `/data/import-from-almt` 等 |
