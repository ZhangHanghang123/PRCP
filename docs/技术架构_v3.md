## 3. 关键架构

### 3.1 64+64 期限桶共享模块（v2.2）

**后端**：`backend/app/services/buckets.py`
```python
def _build_buckets() -> List[Dict[str, str]]:
    monthly_5y = [{"key": f"m{n}", "name": f"{n}M"} for n in range(1, 61)]
    long = [{"key": "y10", "name": "10Y"}, {"key": "y15"}, {"key": "y20"}, {"key": "y30"}]
    return monthly_5y + long  # 64 buckets

ORIG_COLS = [f"orig_{b['key']}" for b in BUCKETS]  # 64 cols
REM_COLS = [f"rem_{b['key']}" for b in BUCKETS]    # 64 cols

def all_select_sql(prefix="") -> str:
    return ", ".join(f"{prefix}{c}" for c in ORIG_COLS + REM_COLS)
```

**前端**：`frontend/src/constants/buckets.ts`
```ts
export const BUCKETS: BucketItem[] = [
  ...Array.from({length: 12}, (_, i) => i+1).map(n => ({key: `m${n}`, name: `${n}M`})),
  ...Array.from({length: 12}, (_, i) => i+13).map(n => ({key: `m${n}`, name: `${n}M`})),
  ...Array.from({length: 12}, (_, i) => i+25).map(n => ({key: `m${n}`, name: `${n}M`})),
  ...Array.from({length: 12}, (_, i) => i+37).map(n => ({key: `m${n}`, name: `${n}M`})),
  ...Array.from({length: 12}, (_, i) => i+49).map(n => ({key: `m${n}`, name: `${n}M`})),
  {key: 'y10'}, {key: 'y15'}, {key: 'y20'}, {key: 'y30'},
];  // 共64桶
```

**业务影响**：
- `prcp_data_basic` 与 `prcp_data_reverse` 各 128 期限桶列（orig × 64 + rem × 64）
- routers/basic.py + data_reverse.py 用 `all_select_sql()` 动态生成 SELECT
- reverse_calc_engine.py INSERT 改动态列名 + m_idx → rem_m(m_idx+1)

## 8. 关键技术决策

1. **FastAPI + SQLAlchemy 2**：类型安全 + ORM 强大
2. **软删除统一模式**：所有表都有 `is_deleted` + `created_by/updated_by/created_at/updated_at`
3. **物化路径 + parent_id**：COA 树形用双策略，查询快且能拖拽
4. **DictProvider Context**：替代硬编码中文，全局字典缓存
5. **函数指标 importlib**：白名单 + 动态加载 + 热重载
6. **软删除 + UNIQUE 复活**：避免 1062 冲突的通用模式
7. **64 桶共享模块**：前后端共用 buckets.py/buckets.ts
8. **JWT 拦截器**：axios 拦截器 + 401 静默 + 防重试风暴
9. **nginx 子路径部署**：`vite base:'/prcp/'` + BrowserRouter basename
10. **git 部署**：`git@github.com:ZhangHanghang123/PRCP.git` main 分支

### 10.2 可扩展引擎包 calculate_engine/（v3.5 重构）

> 旧 `services/sim_engine.py`（380 行）+ `routers/sim.py` 里 4 个引擎 endpoint 抽离为可扩展引擎包。

```
backend/app/services/calculate_engine/
├── __init__.py            # 公共 API：get_engine / list_engine_types / register_engine
├── base.py                # EngineBase 抽象基类（run / get_run / list_runs / list_results）
├── registry.py            # 线程安全注册表 + 工厂方法
└── new_business/          # 新业务模拟引擎
    ├── __init__.py        # 自动注册 NewBusinessEngine
    └── engine.py          # NewBusinessEngine 类（原 sim_engine.py 主体）
```

#### 路由拆分
- `routers/sim.py`：11 个方案管理 endpoint（prefix `/sim`）
- `routers/engines.py`：4 个引擎 endpoint（prefix `/engines`）
- **API 路径 100% 兼容**（前端零改动）
- `main.py` 加 `import app.services.calculate_engine.new_business` 触发注册

#### 引擎调用示例
```python
from app.services.calculate_engine import get_engine
engine = get_engine("new_business")
run_id = engine.run(db, scheme_id=1, user={"id": 1}, month_count=60)
```

#### 引擎算法（new_business 5 步）
1. **JOIN coa_node** 取节点元数据
2. **计算 month_new**：新业务 = 当前余额 × (1 + growth_rate/100/12)（月环比）
3. **按 term_ratios 分布**：在 orig_*/rem_* 桶中按 SHORT/MID/LONG/STRUCT 比例填充分布
4. **桶往前推演**：
   - m1~m59 → m0~m58（一档往前推）
   - 长端自循环衰减：`y10 = 旧y10 - y10/60 + y15/120`
   - 短端收新进 / 新进
6. **主指标重算**：total_balance / weighted_rate / interest_amount / risk_weight

#### 新引擎开发流程
1. 创建子目录 `calculate_engine/<engine_type>/__init__.py` 和 `engine.py`
2. 类继承 `EngineBase`，设置 `engine_type` / `engine_name`
3. 子包 `__init__.py` 调 `register_engine()`
4. 在 `main.py` 加 import 触发注册
