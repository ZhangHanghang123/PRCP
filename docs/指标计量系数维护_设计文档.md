# PRCP 指标计量系数维护 — 设计文档（2026-09-23）

> 数据维护 → 指标计量系数维护。参考 `docs/指标计量系数表.xlsx`。

## 1. 业务背景

用于维护**账户册 × 指标类型 × 数据日期**三个维度下的**当前值 + 未来 1~5 年预测值**，服务于后续的资本充足率、流动性、利率风险等指标的滚动测算与压力测试场景。

| 字段 | 说明 |
|------|------|
| 指标类型 | 5 个核心指标：ROE / CET1 / LCR / NSFR / △EVE |
| 时间维度 | 当前 + 未来 1~5 年（共 6 期） |
| 维度 | 账户册方案 × 账户册节点 × 数据日期 × 指标类型 |
| 单位 | 百分比（默认）/ 绝对值 |

## 2. 数据库设计

### 2.1 主表 `prcp_metric_coefficient`

| 列 | 类型 | 约束 | 说明 |
|----|------|------|------|
| `id` | VARCHAR(128) | PK | `{scheme_code}_{node_code}_{metric_code}_{YYYYMMDD}` |
| `scheme_id` | INT | NN | 账户册方案 id |
| `scheme_code` | VARCHAR(64) | NN | 账户册方案编码 |
| `node_id` | INT | NN | 账户册节点 id |
| `node_code` | VARCHAR(64) | NN | 账户册编码 |
| `metric_type` | VARCHAR(32) | NN | 指标类型（字典 METRIC_TYPE） |
| `metric_code` | VARCHAR(32) | NN | 指标码值（默认 = metric_type） |
| `data_date` | DATE | NN | 数据日期 |
| `current_value` | DECIMAL(20,6) | DF=0 | 当前值 |
| `y1_value` ~ `y5_value` | DECIMAL(20,6) | DF=0 | 未来 1~5 年值 |
| `unit` | VARCHAR(16) | DF='PERCENT' | 计量单位（字典 METRIC_UNIT） |
| `description` | VARCHAR(500) | - | 备注 |
| `status` / `is_deleted` / `created_*` / `updated_*` | 公用 | - | 与 PRCP 其他表一致 |

**索引**：
- PK：`id`
- UQ：`uk_mc_unique (scheme_code, node_code, metric_code, data_date, is_deleted)`
- IDX：`idx_mc_scheme_date`、`idx_mc_node_date`、`idx_mc_metric_type`、`idx_mc_updated`

### 2.2 字典 `sys_dict` 新增

- `METRIC_TYPE`：ROE / CET1 / LCR / NSFR / DELTA_EVE（5 项）
- `METRIC_UNIT`：PERCENT / ABSOLUTE（2 项）

## 3. ID 生成规则

```
id = {scheme_code}_{node_code}_{metric_code}_{YYYYMMDD}
例：COA_V6_ZX_A011_ROE_20260831
```

- 后端 `_build_id()` 在 POST 时强制生成，覆盖提交里的 id 字段
- 修改方案/节点/指标类型/数据日期中任一项 → 生成新记录（不更新原记录）
- 同一组合已存在 → 抛 400 "记录已存在"

## 4. 后端 API（`/metric-coefficient`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `""` | 列表（支持 scheme_id / node_id / metric_type / data_date / keyword 筛选） |
| GET | `/options` | 下拉选项：方案 / 节点 / 指标类型 / 单位 |
| GET | `/nodes-by-scheme` | 按方案联动节点（前端下拉用） |
| POST | `""` | 新增（自动生成 ID，校验节点属于方案） |
| PUT | `/{id}` | 更新 6 期数值 + 备注 + 单位 + 状态 |
| DELETE | `/{id}` | 软删 |
| POST | `/import` | Excel 批量导入（覆盖式更新已存在） |
| GET | `/export-template` | 下载导入模板 |

## 5. 前端设计

- 菜单：数据维护 → **10. 指标计量系数维护**
- 路由：`/metric-coefficient`
- 顶部：4 个 KPI 统计（记录总数 / 覆盖方案数 / 覆盖节点数 / 覆盖指标类型）
- 筛选条：账户册方案 / 指标类型 / 数据日期 / 关键字搜索
- 表格列：ID / 数据日期 / 方案 / 节点 / 指标类型 / 当前值 / 未来1~5年 / 单位 / 状态 / 操作
- 操作：新增、编辑（值+备注+单位+状态）、删除、导入 Excel、下载模板
- 跨字段联动：选账户册方案 → 节点下拉自动过滤

## 6. 校验规则

| 规则 | 错误信息 |
|------|----------|
| 方案不存在 | "账户册方案不存在" |
| 节点不存在 | "账户册节点不存在" |
| 节点不属于该方案 | "节点不属于该方案（节点 scheme_id={N}）" |
| 节点编码与表不一致 | "节点编码不一致" |
| 方案编码与表不一致 | "方案编码不一致" |
| 指标类型不在字典中 | "指标类型 X 不在 METRIC_TYPE 字典中" |
