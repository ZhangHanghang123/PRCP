> 配套产品原型：`docs/产品原型设计_v2.md`

## 1. 设计总览

### 1.1 表清单（25 张业务表 + 4 张系统表 = 29 张）

```
┌─ 公共字段 ─────────────────────────────────────────┐
│ id BIGINT AUTO_INCREMENT PRIMARY KEY              │
│ is_deleted TINYINT(1) DEFAULT 0                   │
│ created_by BIGINT                                 │
│ updated_by BIGINT                                 │
│ created_at DATETIME DEFAULT CURRENT_TIMESTAMP     │
│ updated_at DATETIME DEFAULT CURRENT_TIMESTAMP     │
│              ON UPDATE CURRENT_TIMESTAMP          │
└────────────────────────────────────────────────────┘

[账户册模块 4 张]
  sys_user, sys_role, sys_permission, sys_role_permission,
  prcp_coa_scheme,           -- 账户册方案
  prcp_coa_node,             -- 账户册节点（树形）
  prcp_dict_type,            -- 字典分类
  prcp_dict_item,            -- 字典项

[报表模块 2 张]
  prcp_rpt_report,           -- 报表定义（6 类）
  prcp_rpt_item,             -- 报表表项（树形）

[数据维护模块 7 张]
  prcp_data_balance,         -- 资产负债表（24 月缺口）
  prcp_data_finance,         -- 账务结果指标
  prcp_data_key_param,       -- 关键参数指标
  prcp_data_scale,           -- 规模指标
  prcp_data_price,           -- 价格指标
  prcp_data_fee,             -- 中收指标
  prcp_data_rwa,             -- 资本与 RWA 假设指标

[指标管理模块 2 张]
  prcp_kpi_definition,       -- 指标定义（含公式）
  prcp_kpi_value,            -- 指标值（按日期+版本）

[模型管理模块 3 张]
  prcp_model_version,        -- 模型参数版本（含父版本）
  prcp_model_param,          -- 模型参数（关联指标）
  prcp_model_train_task,     -- 训练任务

[组合反算模块 2 张]
  prcp_reverse_scenario,     -- 反算方案
  prcp_reverse_result,       -- 反算结果（20 年）

[审计日志 1 张]
  prcp_audit_log             -- 审计日志（所有写操作）
```

### 1.2 ER 关系图

```
sys_user ──→ sys_role ──→ sys_role_permission ──→ sys_permission
   │
   └──→ 所有业务表的 created_by / updated_by

prcp_coa_scheme (1) ──→ (N) prcp_coa_node
                              │ │
                              │ └──→ 自身（parent_id 树形）
                              │
                              └──→ prcp_data_balance / node_id

prcp_rpt_report (1) ──→ (N) prcp_rpt_item
                              │
                              ├──→ 自身（parent_id 树形）
                              └──→ prcp_kpi_definition / rpt_id

prcp_data_* (7 张指标) ──→ prcp_rpt_item / item_id
                       └──→ prcp_coa_node / node_id (分子分母)

prcp_kpi_definition (1) ──→ (N) prcp_kpi_value
                                    │
                                    └──→ 数据日期 + 版本

prcp_model_version (1) ──→ (N) prcp_model_param
                                    │
                                    └──→ prcp_kpi_definition / kpi_id

                                    │
                                    └──→ prcp_data_balance / balance_id

                                    │
                                    ├──→ prcp_model_version / version_id
```

### 3.2 `prcp_coa_node` — 账户册节点（树形）

```sql
CREATE TABLE prcp_coa_node (
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  scheme_id       BIGINT NOT NULL,                  -- FK → prcp_coa_scheme
  node_code       VARCHAR(32) NOT NULL,             -- 方案内唯一
  node_name       VARCHAR(64) NOT NULL,
  parent_id       BIGINT,                            -- 自引用 NULL=根
  node_level      INT DEFAULT 1,                     -- 冗余，触发器更新
  node_type       VARCHAR(16),                       -- ASSET/LIABILITY/EQUITY/INCOME/EXPENSE
  path            VARCHAR(255),                      -- 物化路径: '/1/2/3/'
  sort_order      INT DEFAULT 0,
  status          VARCHAR(16) DEFAULT 'ACTIVE',
  description     TEXT,
  is_deleted      TINYINT(1) DEFAULT 0,
  created_by      BIGINT,
  updated_by      BIGINT,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scheme_code (scheme_id, node_code),
  INDEX idx_parent (parent_id),
  INDEX idx_scheme (scheme_id),
  INDEX idx_path (path)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**树形查询**：
```sql
-- 整棵树（按 path 排序天然有序）
SELECT * FROM prcp_coa_node WHERE scheme_id=? AND is_deleted=0 ORDER BY path, sort_order;

-- 查所有子节点
SELECT * FROM prcp_coa_node WHERE path LIKE '/1/2/%' AND is_deleted=0;
```

### 5.2 6 类指标数据表（统一结构）

6 张表结构完全一致，仅表名不同。字段说明：

```sql
-- 通用结构（以 prcp_data_finance 为例，其他 5 张类同）
CREATE TABLE prcp_data_finance (     -- 账务结果指标
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  rpt_item_id     BIGINT NOT NULL,                  -- FK → 报表表项
  coa_node_id     BIGINT,                            -- 关联账户册节点（分子或分母项的主节点）
  data_date       DATE NOT NULL,
  current_value   DECIMAL(20,6),
  numerator_coa_nodes JSON,                            -- 分子项：账户册节点 ID 列表
  denominator_coa_nodes JSON,                          -- 分母项：账户册节点 ID 列表
  calc_formula    TEXT,                              -- 计算公式快照
  description     TEXT,
  is_deleted      TINYINT(1) DEFAULT 0,
  created_by      BIGINT,
  updated_by      BIGINT,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_item_date (rpt_item_id, data_date),
  INDEX idx_date (data_date),
  INDEX idx_item (rpt_item_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 6 张表的命名
prcp_data_finance          -- 账务结果指标
prcp_data_key_param        -- 关键参数指标
prcp_data_scale            -- 规模指标
prcp_data_price            -- 价格指标
prcp_data_fee              -- 中收指标
prcp_data_rwa              -- 资本与 RWA 假设指标
```

**说明**：xlsx 要求 6 类指标都"按数据日期和报表结构维护"，且分子分母项选择账户册节点，因此 6 张表结构一致。前端用同一个页面组件，根据 `data_type` 切换表。

## 10. 关键 SQL 视图（用于 Dashboard 和导出）

### 10.1 `v_prcp_kpi_latest` — 指标最新值

```sql
CREATE OR REPLACE VIEW v_prcp_kpi_latest AS
SELECT
  kd.id, kd.kpi_code, kd.kpi_name, kd.rpt_id,
  kv.data_date, kv.version, kv.current_value,
  kv.prev_value, kv.prev_year_value,
  (kv.current_value - kv.prev_value) / NULLIF(kv.prev_value, 0) AS mom_ratio,
  (kv.current_value - kv.prev_year_value) / NULLIF(kv.prev_year_value, 0) AS yoy_ratio,
  kd.threshold_min, kd.threshold_max,
  CASE WHEN kd.threshold_min IS NOT NULL AND kv.current_value < kd.threshold_min THEN 'BELOW_MIN'
       WHEN kd.threshold_max IS NOT NULL AND kv.current_value > kd.threshold_max THEN 'ABOVE_MAX'
       ELSE 'NORMAL' END AS threshold_status
FROM prcp_kpi_definition kd
LEFT JOIN prcp_kpi_value kv ON kv.kpi_id = kd.id
  AND kv.is_deleted = 0
  AND kv.data_date = (SELECT MAX(data_date) FROM prcp_kpi_value WHERE kpi_id = kd.id AND is_deleted = 0);
```

### 10.2 `v_prcp_balance_summary` — 资负表汇总

```sql
CREATE OR REPLACE VIEW v_prcp_balance_summary AS
SELECT
  cn.scheme_id, cs.scheme_code, cs.scheme_name,
  cn.node_type, cn.path,,
  SUM(db.current_amount) AS total_amount,
  SUM(COALESCE(db.m1_gap, 0)) AS m1_total,
  SUM(COALESCE(db.m12_gap, 0)) AS m12_total,
  SUM(COALESCE(db.m24_gap, 0)) AS m24_total,
  MAX(db.data_date) AS latest_date
FROM prcp_coa_node cn
JOIN prcp_coa_scheme cs ON cs.id = cn.scheme_id
LEFT JOIN prcp_data_balance db ON db.coa_node_id = cn.id AND db.is_deleted = 0
WHERE cn.is_deleted = 0 AND cn.parent_id IS NULL  -- 仅一级节点
GROUP BY cn.scheme_id, cs.scheme_code, cs.scheme_name, cn.node_type, cn.path;
```
