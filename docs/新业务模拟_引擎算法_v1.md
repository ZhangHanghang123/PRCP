## 1. 引擎定位

### 1.1 业务目标
对固定账户册按月滚动（到期还本+续作+新业务叠加），从**基准月**开始按月滚动生成未来 N 个月（默认 24）的"基础数据表快照"，用于：
- 反算驾驶舱的预测输入
- 5/7/8 类监管报表的来源数据
- 资产负债结构压力测试

### 1.2 数据流

```
prcp_sim_scheme (方案)
  ├─ coa_scheme_id → prcp_coa_scheme (账户册方案)
  ├─ data_date (基准月, e.g. 2026-09-01)
  └─ prcp_sim_node_config (节点配置)
       ├─ coa_node_id → prcp_coa_node (L3+ 叶子节点)
       ├─ annual_growth_rate (年化增长比例)
       └─ prcp_sim_term_ratio (期限占比子表)
            ├─ term_value (1~60 月)
            ├─ business_ratio (业务占比%, 求和=100%)
            └─ interest_rate (新业务利率%, 用于加权平均利率)

            ↓ (引擎按月滚动算法)

prcp_sim_run (执行记录)
  ├─ sim_scheme_id, base_data_date, month_count
  ├─ status: PENDING/RUNNING/SUCCESS/FAILED
  └─ progress (0-100)

prcp_sim_result (快照结果)
  ├─ sim_scheme_code, run_id, data_date, date_offset (1..24)
  ├─ coa_node_id, coa_scheme_id
  └─ 64+64 桶 + 4 主指标 (与 prcp_data_basic 一致)
```

## 2. 核心算法（5 步）

### 2.1 算法概览

**输入**：
- 模拟方案：`sim_scheme_id`
- 基准月：`T = scheme.data_date`
- 节点配置：每个 L3+ 叶子节点的 `annual_growth_rate` + `term_ratios[]`

**输出**：
- `prcp_sim_result` 表 N 行/节点 × N 个月（M1..M24）

**初始状态**：
- 从 `prcp_data_basic` 取 `T` 月数据（基础数据表）
  - 64+64 桶：`orig_m1..m60/y10/y15/y20/y30` + `rem_m1..m60/y10/y15/y20/y30`
  - 主指标：`current_balance` / `avg_balance` / `weighted_rate` / `interest_amount`

### 2.2 步骤一：取基础数据

```python
def get_initial_state(coa_scheme_id: int, base_date: str, coa_node_id: int):
    """取基础数据表 T 月数据（date_offset=0 视为"当下")"""
    row = db.execute(text("""
        SELECT orig_m1, orig_m2, ..., orig_y10, orig_y15, orig_y20, orig_y30,
               rem_m1, ..., rem_y30,
               current_balance, avg_balance, weighted_rate, interest_amount
        FROM prcp_data_basic
        WHERE coa_node_id=:nid AND data_date=:d AND date_offset=0 AND offset_unit='D'
          AND is_deleted=0
    """), {"nid": coa_node_id, "d": base_date}).first()
    return row_to_state(row)
```

**注意**：
- `data_date` 是基础数据表的月份，T 月 = scheme.data_date
- `date_offset = 0, offset_unit = 'D'` 表示"基准日数据"（具体看 prcp_data_basic 数据约定）
- 如果不存在：跳过该节点（不参与模拟）

### 2.3 步骤二：计算当月新增量

```python
def compute_month_new(state, annual_growth_rate):
    """当月新增量 = rem_m1（当月到期）+ 净新增量"""
    net_new = state.current_balance * annual_growth_rate / 12
    month_new = state.rem_m1 + net_new
    return net_new, month_new
```

公式：
- `net_new = current_balance × annual_growth_rate / 12`（线性月增长）
- `month_new = rem_m1 + net_new`（老业务到期 + 新业务净增）

### 2.4 步骤三：按期限拆分 + 叠加

```python
def apply_term_split(state, month_new, term_ratios):
    """按 term_ratios 拆分 month_new，加到 orig_mv + rem_mv"""
    for ratio in term_ratios:
        v = ratio.term_value  # 1..60
        b_pct = ratio.business_ratio  # 0..100
        amount_v = month_new * b_pct / 100
        
        # 原始期限桶 + 剩余期限桶
        state[f'orig_m{v}'] += amount_v
        state[f'rem_m{v}'] += amount_v
    return state
```

注意：
- `term_value` 范围 1~60（已在 DB CHECK 约束）
- `business_ratio` 求和=100%（应用层校验，已实现）
- 业务期限 1~60 月精确对应 `orig_m1..m60` + `rem_m1..m60`
- 超过 60 月的期限（未来扩展）：归入 `y10` 桶

### 2.5 步骤四：桶往前推一月

```python
def roll_one_month(state):
    """所有桶往前推一月：m1=旧m2, m2=旧m3, ..., m60=旧y10/60
    长端桶：y10=旧y10-旧y10/60+旧y15/120, y15=旧y15-旧y15/120+旧y20/120, etc.
    """
    new_state = {}
    
    # 原始期限桶（orig_*）
    for v in range(1, 60):  # m1..m59
        new_state[f'orig_m{v}'] = state[f'orig_m{v+1}']
    new_state['orig_m60'] = state['orig_y10'] / 60
    new_state['orig_y10'] = state['orig_y10'] - state['orig_y10']/60 + state['orig_y15']/120
    new_state['orig_y15'] = state['orig_y15'] - state['orig_y15']/120 + state['orig_y20']/120
    new_state['orig_y20'] = state['orig_y20'] - state['orig_y20']/120 + state['orig_y30']/240
    new_state['orig_y30'] = state['orig_y30'] - state['orig_y30']/240
    
    # 剩余期限桶（rem_*）同样的逻辑
    for v in range(1, 60):
        new_state[f'rem_m{v}'] = state[f'rem_m{v+1}']
    new_state['rem_m60'] = state['rem_y10'] / 60
    new_state['rem_y10'] = state['rem_y10'] - state['rem_y10']/60 + state['rem_y15']/120
    new_state['rem_y15'] = state['rem_y15'] - state['rem_y15']/120 + state['rem_y20']/120
    new_state['rem_y20'] = state['rem_y20'] - state['rem_y20']/120 + state['rem_y30']/240
    new_state['rem_y30'] = state['rem_y30'] - state['rem_y30']/240
    
    return new_state
```

**关键边界**：
- 长端桶按月摊销：
  - `y10`（5-10 年 = 60-120 月）→ 1 月/60 月 = 1/60 摊到 m60，1/120 滚入 y10 上一格
  - `y15`（10-15 年 = 120-180 月）→ 1/120 摊到 y10 上一格，1/120 滚入 y15 上一格
  - `y20`（15-20 年 = 180-240 月）→ 1/120 摊到 y15 上一格，1/240 滚入 y20 上一格
  - `y30`（20-30 年 = 240-360 月）→ 1/240 摊到 y20 上一格，剩余
- 这种"自循环"模型让长端桶持续按月衰减，长期趋零

### 2.6 步骤五：主表指标重算

```python
def compute_main_metrics(state, annual_growth_rate, term_ratios, net_new, month_new):
    """重算 4 个主指标"""
    # 1. 当前余额
    new_current_balance = state.current_balance * (1 + annual_growth_rate / 12)
    
    # 2. 平均余额 = 旧平均 + (旧当前 × 月增长率 / 2)
    # 数学含义：当月平均 ≈ (期初 + 期末) / 2 = 旧当前 + 净新增/2
    new_avg_balance = state.avg_balance + state.current_balance * annual_growth_rate / 12 / 2
    
    # 3. 加权平均利率 = (旧平均×旧利率 + 新增按期限金额×各期限利率) / (旧平均 + 新增总额)
    weighted_new_amount = sum(
        (month_new * ratio.business_ratio / 100) * ratio.interest_rate
        for ratio in term_ratios
    )
    # 注意：Σ(business_ratio) = 100，所以 sum(各期限金额) = month_new
    new_weighted_rate = (
        (state.avg_balance * state.weighted_rate + weighted_new_amount)
        / (state.avg_balance + month_new)
        if (state.avg_balance + month_new) > 0 else 0
    )
    
    # 4. 当月利息 = 新平均余额 × 新利率 / 12
    new_interest_amount = new_avg_balance * new_weighted_rate / 12
    
    return new_current_balance, new_avg_balance, new_weighted_rate, new_interest_amount
```

公式说明：
- `current_balance`：按月复利 `× (1 + growth/12)`
- `avg_balance`：滚动平均 `+= 净新增 / 2`
- `weighted_rate`：分子 = 旧加权利息 + 新业务利息贡献，分母 = 旧平均 + 新增
- `interest_amount`：当月应计利息（按 1/12 计提）

### 2.7 主循环

```python
def run_engine(scheme_id: int, month_count: int = 24):
    scheme = get_scheme(scheme_id)
    base_date = scheme.data_date  # 基准月
    coa_scheme_id = scheme.coa_scheme_id
    
    # 取所有 L3+ 叶子节点 + 配置
    nodes = get_configured_nodes(scheme_id)  # 只跑已配置的节点
    
    # 初始状态（每个节点）
    states = {
        node.id: get_initial_state(coa_scheme_id, base_date, node.id)
        for node in nodes
        if has_initial_data(node.id, base_date)
    }
    
    # 按月滚动
    for k in range(1, month_count + 1):
        data_date_k = add_months(base_date, k)  # T+k
        results_k = []
        
        for node in nodes:
            state = states[node.id]
            config = get_node_config(scheme_id, node.id)
            
            # 步骤二
            net_new, month_new = compute_month_new(state, config.annual_growth_rate)
            
            # 步骤三
            state = apply_term_split(state, month_new, config.term_ratios)
            
            # 步骤四
            state = roll_one_month(state)
            
            # 步骤五
            new_cb, new_ab, new_wr, new_ia = compute_main_metrics(
                state, config.annual_growth_rate, config.term_ratios,
                net_new, month_new,
            )
            
            # 更新 state
            state.current_balance = new_cb
            state.avg_balance = new_ab
            state.weighted_rate = new_wr
            state.interest_amount = new_ia
            
            # 保存结果（写 prcp_sim_result）
            results_k.append({
                'sim_scheme_code': scheme.scheme_code,
                'sim_scheme_id': scheme.id,
                'run_id': run.id,
                'data_date': data_date_k,
                'date_offset': k,
                'coa_scheme_id': coa_scheme_id,
                'coa_node_id': node.id,
                'node_code': node.code,
                ... # 节点元数据
                **state.orig, **state.rem,  # 64+64 桶
                'current_balance': new_cb,
                'avg_balance': new_ab,
                'weighted_rate': new_wr,
                'interest_amount': new_ia,
            })
        
        # 批量 INSERT prcp_sim_result
        bulk_insert_sim_result(results_k)
        
        # 更新进度
        update_run_progress(run.id, k, month_count)
    
    return run.id
```

## 3. DB Schema 增量

### 3.1 prcp_sim_run（执行记录表）

```sql
CREATE TABLE IF NOT EXISTS prcp_sim_run (
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  sim_scheme_id   BIGINT NOT NULL                      COMMENT 'FK → prcp_sim_scheme.id',
  sim_scheme_code VARCHAR(32) NOT NULL                 COMMENT '冗余：方案编码',
  base_data_date  DATE NOT NULL                        COMMENT '基准月（=scheme.data_date）',
  month_count     INT DEFAULT 24                       COMMENT '生成月份数（默认 24）',
  target_data_date DATE                                COMMENT '目标月（=base + month_count 月）',
  status          VARCHAR(16) DEFAULT 'PENDING'        COMMENT 'PENDING/RUNNING/SUCCESS/FAILED/CANCELLED',
  progress        INT DEFAULT 0                        COMMENT '进度 0-100',
  total_nodes     INT DEFAULT 0                        COMMENT '本次执行的节点总数',
  processed_nodes INT DEFAULT 0                        COMMENT '已处理节点数',
  duration_ms     BIGINT                               COMMENT '执行耗时（毫秒）',
  error_message   TEXT,
  started_at      DATETIME,
  finished_at     DATETIME,
  created_by      BIGINT,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_sim_scheme (sim_scheme_id),
  INDEX idx_status (status),
  INDEX idx_created (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='新业务模拟执行记录';
```

### 3.2 prcp_sim_result（快照结果表）

```sql

  node_name       VARCHAR(64),

  parent_code     VARCHAR(32),
  is_leaf         TINYINT(1) DEFAULT 0,

  -- 原始期限金额（64 桶：m1~m60 + y10/y15/y20/y30）

  INDEX idx_node (coa_node_id)
```

## 6. 关键边界与异常

| 边界 | 处理 |
|------|------|
| 节点无 prcp_data_basic 初始数据 | 跳过该节点（warning 日志） |
| 节点无 prcp_sim_node_config 配置 | 跳过（不参与模拟） |
| 业务占比求和 ≠ 100% | 已在参数配置页校验；引擎运行时若发现仍不通过，标记 FAILED |
| 月份跨越到 prcp_data_basic 不存在的月份 | 用最后一期 prcp_data_basic 数据继续滚动 |
| 长端桶连续衰减趋零 | 数值上趋零，不会无限增长（数学保证） |
| 同方案重复触发 | 创建新 run_id，旧 run 保留 |
| 引擎执行超时 | timeout=60s 报错 → run.status=FAILED |
