## 2. 表设计

### 2.1 prcp_sim_scheme（新业务模拟方案主表）

**业务含义**：每个方案绑定一个账户册方案（prcp_coa_scheme），承载一组节点配置。

```sql
CREATE TABLE IF NOT EXISTS prcp_sim_scheme (
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  scheme_code     VARCHAR(32) NOT NULL,
  scheme_name     VARCHAR(64) NOT NULL,
  coa_scheme_id   BIGINT NOT NULL                          -- FK → prcp_coa_scheme.id
  description     TEXT,
  config_node_count INT DEFAULT 0,                          -- 冗余字段：已配置节点数
  status          VARCHAR(16) DEFAULT 'ACTIVE',            -- ACTIVE/INACTIVE
  is_deleted      TINYINT(1) DEFAULT 0,
  created_by      BIGINT,
  updated_by      BIGINT,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scheme_code (scheme_code, is_deleted),    -- 方案编码 + 未删除唯一（软删除 + UNIQUE 复活）
  INDEX idx_coa_scheme (coa_scheme_id),
  INDEX idx_status (status),
  CONSTRAINT fk_sim_scheme_coa FOREIGN KEY (coa_scheme_id)
    REFERENCES prcp_coa_scheme(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='新业务模拟方案';
```

**关键设计**：
- `coa_scheme_id` 创建后不可变更（应用层禁止修改）
- `config_node_count` 冗余字段，避免前端每次列表查询都 JOIN 计数
- `UNIQUE KEY (scheme_code, is_deleted)` 软删除 + UNIQUE 复活机制

### 2.2 prcp_sim_node_config（节点配置表）

**业务含义**：每个方案下每个 L3+ 叶子节点一条配置，包含年化增长率 + 默认期限单位。

```sql
CREATE TABLE IF NOT EXISTS prcp_sim_node_config (
  id                  BIGINT AUTO_INCREMENT PRIMARY KEY,
  scheme_id           BIGINT NOT NULL,                     -- FK → prcp_sim_scheme.id
  coa_node_id         BIGINT NOT NULL,                     -- FK → prcp_coa_node.id
  coa_node_code       VARCHAR(32),                         -- 冗余：节点编码（兼容历史归档）
  annual_growth_rate  DECIMAL(8,4) DEFAULT 0,              -- 年化目标增长率（%）
  term_unit           VARCHAR(8) DEFAULT 'MONTH',          -- 期限单位 ENUM（当前固定 MONTH）
  term_count          INT DEFAULT 0,                       -- 冗余：当前配置的期限条数
  remark              TEXT,
  is_deleted          TINYINT(1) DEFAULT 0,
  created_by          BIGINT,
  updated_by          BIGINT,
  created_at          DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at          DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scheme_node (scheme_id, coa_node_id, is_deleted),
  INDEX idx_scheme (scheme_id),
  INDEX idx_node (coa_node_id),
  CONSTRAINT fk_sim_cfg_scheme FOREIGN KEY (scheme_id)
    REFERENCES prcp_sim_scheme(id),
  CONSTRAINT fk_sim_cfg_node FOREIGN KEY (coa_node_id)
    REFERENCES prcp_coa_node(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='新业务模拟节点配置';
```

**关键设计**：
- `annual_growth_rate` 用 DECIMAL(8,4) 支持小数百分比（0~100 范围足够）
- `term_unit` 当前固定 `MONTH`，未来可扩展 `DAY`/`YEAR`（不影响业务）
- `coa_node_code` 冗余存储，节点被删除后配置仍可读（历史归档）
- 软删除 + UNIQUE 复活：`UNIQUE KEY (scheme_id, coa_node_id, is_deleted)`，避免同节点重复配置冲突

### 2.3 prcp_sim_term_ratio（期限占比明细表）

**业务含义**：每个节点配置下的多行期限占比明细，业务占比之和必须=100%。

```sql
CREATE TABLE IF NOT EXISTS prcp_sim_term_ratio (
  id              BIGINT AUTO_INCREMENT PRIMARY KEY,
  config_id       BIGINT NOT NULL,                         -- FK → prcp_sim_node_config.id
  term_value      INT NOT NULL,                            -- 期限值（1~60 月）
  term_unit       VARCHAR(8) DEFAULT 'MONTH',              -- 期限单位（与 prcp_sim_node_config.term_unit 一致）
  business_ratio  DECIMAL(8,4) NOT NULL,                   -- 业务占比（%），0~100
  sort_order      INT DEFAULT 0,                           -- 显示顺序
  remark          VARCHAR(255),
  is_deleted      TINYINT(1) DEFAULT 0,
  created_by      BIGINT,
  updated_by      BIGINT,
  created_at      DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at      DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_config (config_id),
  INDEX idx_term (term_value, term_unit),
  CONSTRAINT fk_sim_ratio_cfg FOREIGN KEY (config_id)
    REFERENCES prcp_sim_node_config(id),
  CONSTRAINT chk_term_value CHECK (term_value BETWEEN 1 AND 60),
  CONSTRAINT chk_business_ratio CHECK (business_ratio >= 0 AND business_ratio <= 100)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='新业务期限占比明细';
```

**关键设计**：
- 应用层校验：业务占比之和必须=100%（DB 层不强制 CHECK，避免单行 INSERT 时暂未满足）
- `term_value` DB 层 CHECK 1~60（防止非法期限值）
- `business_ratio` DB 层 CHECK 0~100（防止非法百分比）
- `sort_order` 支持子表拖拽排序
- 软删除：删除节点配置时级联软删子表

## 3. SQL 升级脚本

**文件**：`backend/scripts/upgrade_sim_scheme.sql`

```sql
-- ============================================================
-- 新业务模拟方案 3 张表 升级脚本
-- 时间：2026-09-21
-- ============================================================

USE prcp_db;

-- 幂等保护：每张表先检查存在性
SET @t_exists := (
  SELECT COUNT(*) FROM information_schema.TABLES
  WHERE TABLE_SCHEMA = 'prcp_db' AND TABLE_NAME = 'prcp_sim_scheme'
);
SET @sql := IF(@t_exists = 0, '
CREATE TABLE prcp_sim_scheme (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  scheme_code VARCHAR(32) NOT NULL,
  scheme_name VARCHAR(64) NOT NULL,
  coa_scheme_id BIGINT NOT NULL,
  description TEXT,
  config_node_count INT DEFAULT 0,
  status VARCHAR(16) DEFAULT "ACTIVE",
  is_deleted TINYINT(1) DEFAULT 0,
  created_by BIGINT,
  updated_by BIGINT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  UNIQUE KEY uk_scheme_code (scheme_code, is_deleted),
  INDEX idx_coa_scheme (coa_scheme_id),
  INDEX idx_status (status),
  CONSTRAINT fk_sim_scheme_coa FOREIGN KEY (coa_scheme_id) REFERENCES prcp_coa_scheme(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT="新业务模拟方案"', 'SELECT 1');
PREPARE s FROM @sql; EXECUTE s; DEALLOCATE PREPARE s;

-- ...（其余 2 张表类似）
```

## 6. ER 总结

| 表 | 行数预估 | 主要用途 |
|------|---------|----------|
| prcp_sim_scheme | 5-20 | 模拟方案主表 |
| prcp_sim_node_config | 100-2000 | 节点配置（每方案每节点 1 行） |
| prcp_sim_term_ratio | 500-10000 | 期限占比明细（每节点 3-10 行） |

**总计**：约 5 千 ~ 1 万行数据，MySQL 单表轻松支持。
