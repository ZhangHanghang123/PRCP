# 新业务模拟引擎 — 需求分析

> **业务定位**：对固定账户册按月滚动（到期还本+续作+新业务叠加），生成每月末时点的 3 张基础数据表（balance / basic / 派生指标）。
> **本需求范围**：仅包含"方案列表 + 参数配置"两大功能，模拟引擎核心算法按业务诉求另起需求。

---

## 1. 业务背景与目标

### 1.1 业务背景

| 项目 | 说明 |
|------|------|
| 现状 | 数据维护中"7.资产负债表"按月录入静态余额；新业务/到期续作依赖人工滚动 |
| 痛点 | 1) 24 个月手工录入工作量大；2) 利率传导、规模演变无法追溯；3) 无法做"What-If"情景模拟 |
| 解决方案 | 提供"新业务模拟方案"配置能力，作为反算驾驶舱的前置输入 |

### 1.2 业务目标

- **G1** 集中管理账户册的新业务增长策略（增长率 + 期限分布 + 利率分布）
- **G2** 配置一次即可生成未来 N 个月的 3 张基础数据表快照
- **G3** 与现有账户册/指标/反算模块打通，形成"配置→模拟→分析"闭环

## 3. 功能需求

### 3.1 FR1 方案列表（SimSchemeList）

| 编号 | 功能描述 | 优先级 |
|------|---------|--------|
| FR1.1 | 展示所有未删除的模拟方案列表 | P0 |
| FR1.2 | 列表字段：方案编码、方案名称、关联账户册方案、节点配置数、状态、创建人、创建时间、操作 | P0 |
| FR1.3 | 支持按"方案编码 / 方案名称"模糊搜索 | P1 |
| FR1.4 | 支持按"状态"过滤 | P1 |
| FR1.5 | 新增方案（弹出 Modal）：方案编码、方案名称、关联账户册方案（下拉）、描述 | P0 |
| FR1.6 | 编辑方案（仅修改名称/描述/账户册方案不可改） | P0 |
| FR1.7 | 删除方案（软删）+ 状态切换 ACTIVE/INACTIVE | P0 |
| FR1.8 | "参数配置"按钮：跳转至 `/sim/config/:scheme_id` 配置页 | P0 |

### 3.2 FR2 参数配置（SimConfigPage）

| 编号 | 功能描述 | 优先级 |
|------|---------|--------|
| FR2.1 | 页面加载：自动加载方案基础信息 + 关联账户册方案的树形结构 | P0 |
| FR2.2 | 左侧账户册树（DirectoryTree，L1~L5 全展开，可折叠） | P0 |
| FR2.3 | 点击树节点（仅 L3+叶子节点可配置）：右侧加载参数配置面板 | P0 |
| FR2.4 | 右侧"上栏"：新业务年化目标增长比例（输入框，%单位，0~100） | P0 |
| FR2.5 | 右侧"下栏"：新业务期限占比子表，字段为（期限值、期限单位、业务占比%） | P0 |
| FR2.6 | 期限占比子表支持增行 / 删行 / 编辑 | P0 |
| FR2.7 | 期限单位**固定为"月"**（不允许修改，默认值月） | P0 |
| FR2.8 | 子表"业务占比"列**求和=100%** 才能保存，否则提示"占比之和必须为 100%" | P0 |
| FR2.9 | 期限值范围：1~60（与 64 桶期限桶 m1~m60 一致；超过 60 用长端"5年+"标识） | P0 |
| FR2.10 | 切换节点前若已编辑但未保存：弹窗提示"放弃当前修改？" | P0 |
| FR2.11 | 保存按钮：保存当前节点的配置 + 比例子表 | P0 |
| FR2.12 | 重置按钮：清空当前节点配置 | P1 |
| FR2.13 | 显示当前节点的"基础信息"（编码、名称、大类、当前余额）只读 | P1 |

### 3.3 FR3 数据约束

| 编号 | 约束 |
|------|------|
| FR3.1 | 方案编码方案内全局唯一 |
| FR3.2 | 同一方案下同一节点只能有一条配置记录 |
| FR3.3 | 同一节点配置下的期限占比之和必须=100%（应用层校验） |
| FR3.4 | 期限值范围 1~60 月 |
| FR3.5 | 期限占比百分比 0~100（单行） |
| FR3.6 | 删除方案时，级联软删关联的节点配置和期限占比 |
| FR3.7 | 关联账户册方案不允许在编辑时修改（创建后绑定） |

## 4. 非功能需求

| 编号 | 项目 | 描述 |
|------|------|------|
| NFR1 | 性能 | 列表分页 20 条/页；树节点加载 < 500ms |
| NFR2 | 易用性 | 期限占比求和实时校验，绿色 ✓ 100% / 红色 ✗ 错误 |
| NFR3 | 兼容性 | 与现有账户册/数据维护/反算模块 API 解耦 |
| NFR4 | 可维护性 | 沿用 prcp_*_scheme 命名规范 + 软删除 + UNIQUE 复活机制 |
| NFR5 | 审计 | 所有写操作记录 sys_audit_log（v2.5+） |

---

## 5. 边界与异常

| 场景 | 处理 |
|------|------|
| 关联账户册方案已被删除 | 下拉只显示 ACTIVE 的方案；前端校验 |
| 节点在配置期间被删除 | 保存时校验节点存在性，提示"节点已删除，请重新选择" |
| 期限占比求和 ≠100 | 禁止提交，前端按钮置灰 + 后端 400 |
| 方案已绑定下游模拟任务 | 删除时二次确认"将级联删除 N 个配置记录" |
| 同节点并发保存 | 后端 UNIQUE 约束触发 1062，提示"该节点配置已变更，请刷新后重试" |
| 关联账户册方案切换 | 当前不允许（创建后绑定），提供"克隆为新方案"功能 |

## 7. 验收标准

| AC# | 描述 |
|-----|------|
| AC1 | 列表页可正常展示、新增、编辑、删除方案 |
| AC2 | 方案编码重复时前端给出明确提示并阻止提交 |
| AC3 | 参数配置页可正常加载树，节点切换无残留 |
| AC4 | 期限占比求和≠100 时无法保存 |
| AC5 | 期限占比求和=100 时可成功保存，刷新页面数据回显 |
| AC6 | 软删除的方案不显示在列表中，但 DB 数据保留 |
| AC7 | 关联账户册方案不存在时（极端情况）给出友好错误 |

## 8. 风险与依赖

| 风险 | 影响 | 缓解 |
|------|------|------|
| 账户册层级变更 | 配置节点可能失效 | 配置层记录 node_code 而非 id（双写兼容） |
| 多用户同时编辑同一节点 | 末保存者覆盖 | 乐观锁 + UNIQUE 约束 |
| 节点配置数据量过大 | 性能 | 每节点只存最新版本，历史归档至 prcp_sim_node_config_history |
