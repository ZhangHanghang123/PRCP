## 二、4 种增长方式的精确语义

### 2.1 净增长口径 vs 毛投放口径（**最关键差异**）

设第 M 月：
- `B` = 上月末余额（`current_balance`）
- `release` = 当月到期释放（`rem_m1`，存量桶自然到期）
- `add` = 当月新增投放额（由增长配置 + 节奏配置算出）

| growth_type | 名称 | 口径 | `month_new` | 期末余额 |
|---|---|---|---|---|
| **1** | 目标增长百分比 | **净增长** | `release + add` | `B + add`（到期回补，保证净增长） |
| **2** | 目标增长绝对值 | **净增额** | `release + add` | `B + add`（新增额即目标值） |
| **3** | 增长百分比 | **毛投放** | `add` | `B − release + add`（到期自然出表，不回补） |
| **4** | 增长值 | **余额锚定** | `release + (target_B − B)` | `target_B`（**可为负 = 缩表**） |

> **type 1 与 type 3 的本质区别**：
> - type 1 是「银行承诺要增长多少」→ 到期掉的必须补回来，否则实际达不到目标增速
> - type 3 是「新增投放多少」→ 到期归到期，不干预
>
> 举例（B = 100 亿，rate = 12%，release = 5 亿，add = 1 亿）：
> - type 1：投放 6 亿 → 期末 101 亿（净增 1 亿 = 目标）
> - type 3：投放 1 亿 → 期末 96 亿（净减 4 亿，到期 5 亿出表）

### 2.2 各方式的 `add` 计算

```python
UNIT_SCALE = 1e4 if amount_unit == 'WAN' else 1e8    # 万元 / 亿元
year_param = year_values[y - 1]                        # 第 y 年参数

if growth_type == 1:      # 目标增长百分比（净增长口径）
    year_target = B × year_param / 100                 # 年目标增量
    add_y      = year_target × w[m] / 100              # 按节奏拆到月

elif growth_type == 2:    # 目标增长绝对值（净增额口径）
    year_target = year_param × UNIT_SCALE
    add_y      = year_target × w[m] / 100

elif growth_type == 3:    # 增长百分比（毛投放口径）
    year_target = B × year_param / 100
    add_y      = year_target × w[m] / 100              # 不加 release

elif growth_type == 4:    # 增长值（余额锚定，可为负）
    target_B   = year_param × UNIT_SCALE               # 目标期末余额（可为负 → 缩表）
    year_target = target_B − B                         # 可能为负
    add_y      = year_target × w[m] / 100
```

### 2.3 `month_new` 组装

```python
if growth_type in (1, 2):        # 净增长 / 净增额口径 → 到期回补
    month_new = release + add
elif growth_type == 3:            # 毛投放口径 → 不回补
    month_new = add
elif growth_type == 4:            # 余额锚定 → 反算使期末落在 target_B
    month_new = release + add     # add 可为负
```

## 三、完整月度公式（v2.1 定稿）

```python
# ====== 输入 ======
B               = current_balance              # 上月末余额
growth_type     = 1 | 2 | 3 | 4
year_values     = [y1..y5]                     # 5 年参数
rhythm_type     = 1（线性） | 2（自定义）
w[1..12]        = 12 月节奏权重（和 = 100%，线性 = 8.3333%）
term_ratios     = [(v, pct, rate), ...]        # pct 之和 = 100%
unit_scale      = 1e4（万元） | 1e8（亿元）

# ====== 步骤 1：年目标增量 ======
y = 1..5
if growth_type in (1, 3):
    year_target[y] = B × year_values[y-1] / 100
elif growth_type == 2:
    year_target[y] = year_values[y-1] × unit_scale
elif growth_type == 4:
    year_target[y] = year_values[y-1] × unit_scale − B      # 可为负

# ====== 步骤 2+3：按月投放 ======
for M in 1..month_count:                        # month_count ≤ 60
    y          = (M-1) // 12 + 1                # 第 1~5 年
    m_in_year  = (M-1) % 12 + 1                 # 年内第几月（跨年复用同一套 w）

    release    = rem_m1                          # 存量到期释放
    add        = year_target[y] × w[m_in_year] / 100

    if growth_type in (1, 2, 4):
        month_new = release + add                # 净增长口径（type4 的 add 可负）
    else:                                          # growth_type == 3
        month_new = add                           # 毛投放口径，不回补

    # ====== 步骤 3：期限占比落桶 ======
    for (v, pct, rate) in term_ratios:
        amount_v = month_new × pct / 100
        orig_m{v} += amount_v
        rem_m{v}  += amount_v
        # type 4 的 amount_v 可能为负（缩表），允许负值落桶

    # ====== 步骤 4：滚桶 ======
    roll_one_month(state)

    # ====== 主表指标 ======
    if growth_type in (1, 2):
        new_current = B + add                     # 净增额即 add
    elif growth_type == 3:
        new_current = B − release + add           # 到期出表
    elif growth_type == 4:
        new_current = year_values[y-1] × unit_scale × (1 if 该月是年内最后一个月 else 0) ... 
        # 简化：见下方说明
```

> **type 4 余额锚定的实现要点**：
> 每月投放 `add_y = (target_B − B) × w[m] / 100`，全年 `Σadd = target_B − B`，
> 因此**第 12 月末余额恰好 = target_B**（因为 `B + Σadd = B + (target_B − B) = target_B`）。
> 这是「年内按节奏线性逼近年末目标」的效果，月度余额是平滑过渡而非跳变。

## 四、分支 A：不做模型测算（`is_model_calc = 2`）

| 项 | 处理 |
|---|---|
| 新增投放 `add` | `0` |
| `month_new` | `release`（= `rem_m1`，仅自然到期） |
| 桶滚动 | **照常执行** |
| `current_balance` | 不变 |
| `weighted_rate` | 不变（无新增，不稀释） |
| 配置可读性 | **前台保持可编辑**（后续其他程序消费），但不参与本引擎计算 |

**为什么仍要滚桶**：不滚桶会导致期限结构失真（余额永堆短端）、加权利率失真，
且无法与分支 B 的兄弟节点在 SUMMARY 层聚合。分支 A = **只滚桶，不投放**。

## 五、分支 B：完整公式（终版）

```python
# ====== 步骤 1：年目标 ======
y = (M-1)//12 + 1 ; m_in_year = (M-1)%12 + 1

if growth_type in (1, 3):
    year_target = B × year_values[y-1] / 100
elif growth_type == 2:
    year_target = year_values[y-1] × unit_scale
elif growth_type == 4:
    year_target = year_values[y-1] × unit_scale − B      # 可为负

# ====== 步骤 2：节奏拆分 ======
add = year_target × w[m_in_year] / 100

# ====== 到期回补（净增长口径）=====
release = rem_m1
month_new = (release + add) if growth_type in (1,2,4) else add

# ====== 步骤 3：期限落桶 ======
for (v, pct, rate) in term_ratios:
    amount_v = month_new × pct / 100
    orig_m{v} += amount_v ; rem_m{v} += amount_v

# ====== 步骤 4：滚桶 ======
roll_one_month(state)

# ====== 主表指标 ======
new_current  = B + add              # type 3 时 add 已在上面按毛投放口径处理
new_avg      = avg_balance + add / 2
new_wr       = (avg_balance × old_wr + Σ(amount_v × rate_v)) / (avg_balance + month_new)
new_interest = new_avg × new_wr / 12
```

> 注：type 3 时 `new_current = B + add` 仍成立 —— 因为 `rem_m1` 已在 `roll_one_month`
> 后自然从 `rem_m1` 移到更远端/出表，`current_balance` 的减少由滚桶隐含表达，
> 实际计算中 `B − release + add` 与 `B + add − release` 等价。

## 六、边界与异常（v2.1 更新）

| 场景 | 处理 |
|---|---|
| `growth_type = 4` 且 `yearN < 当前余额` | **`year_target` 为负 → 缩表**，`add` 为负 → 期限占比落负值，允许 |
| `growth_type = 4` 且 `yearN` 为负值 | 语义异常，建议前端校验拦截（不能把余额设为负） |
| `month_count > 60` | **不可能**：`MAX_MONTH_COUNT = 60`，与 5 年恰好对齐，无需处理 |
| 节奏权重跨年 | **复用同一套 12 月权重**，`m_in_year = (M-1) % 12 + 1` |
| 未配置 `growth_config` | 5 年参数全 0 → `year_target = 0` → 只滚桶不投放 |
| 未配置 `rhythm` | 默认线性（每月 8.3333%） |
| `term_ratio` 占比和 ≠ 100% | 阻断（前后端双重校验） |
| `rhythm` 权重和 ≠ 100% | 阻断（前后端双重校验） |
| `is_model_calc=2` 但配了期限占比 | 期限占比不参与本引擎；配置保留供其他程序使用 |

## 七、驾驶舱「投放节奏」展示区（新增）

**位置**：驾驶舱页面**最底部**

**展示内容**：

| 区块 | 内容 |
|---|---|
| **月度投放柱状图** | X 轴 = M1~M60（或选定区间），Y 轴 = `month_add`（当月纯新增投放额） |
| **节奏权重对比** | 12 个月权重，线性基准（8.3333%）vs 实际自定义权重，折线对比 |
| **累计投放曲线** | 按 `Σ month_add` 累计，展示与年度目标的逼近关系 |
| **到期释放对照** | `month_release`（灰色柱）vs `month_add`（彩色柱），直观看出净投放效果 |
| **年度汇总表** | Y1~Y5 每年：年目标 / 实际投放 / 达成率 / 年末余额 |

**数据来源**：依赖 `prcp_sim_result` 新增的追溯字段（见第八章）。
