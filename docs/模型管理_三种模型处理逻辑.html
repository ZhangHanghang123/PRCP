模块定位与全景

1.1 模块定位

模型管理是 PRCP 平台的「预测引擎工厂」：把「历史余额 → 未来预测」这段逻辑 从硬编码中抽出来，交给业务人员通过模型 → 版本 → 参数 → 训练任务四层配置来定义。

它与指标管理的关系是：

  • 指标管理回答「现在是多少分」—— 算的是当前值
  • 模型管理回答「未来会怎样」—— 算的是预测值
  • 两者通过 prcp_kpi_value 与 prcp_model_param.kpi_id 打通

◀ INPUT 输入

y　np.array(actual[:12])
空数据　合成 100 + 2.5i + N(0,5)
params　本算法未使用
⇒
OUTPUT 输出 ▶
predicted　12 期预测（x=12..23）

metrics　mae / rmse / r2 / formula

预测　　：ŷ = [x, 1] @ [a, b]，x ∈ [12, 24)
评估　　：MAE / RMSE / R² = 1 − SSres / SStot

◀ INPUT 输入

x　np.arange(18)（一维，不 reshape）
y　np.array(actual[:18])
空数据　合成 S 形 50 + 100/(1+e^(-(i-12)/3))
params　本算法未使用
⇒
OUTPUT 输出 ▶
predicted　6 期预测（x=18..23）
periods　[18..23]

extras　None
拟合模型：y = L / (1 + exp(−k(x − x₀)))　（S 形饱和曲线）

2.4 模型③ 蒙特卡洛模拟

◀ INPUT 输入
基准值　mean(actual[:12])，空则 100.0
params　VOL 命中的参数（年化波动率 %）
抽样　n_sims=1000 × n_periods=12
随机种子　np.random.default_rng(42) 固定
路径　几何布朗运动 exp(ΣN(0,σ_m))
⇒
OUTPUT 输出 ▶
predicted　12 期均值路径
conf_low　5% 分位（90% 置信下界）
conf_high　95% 分位（90% 置信上界）
metrics　n_sims / annual_vol / conf_low[] / conf_high[]
extras　(conf_low, conf_high) 元组
波动率换算：monthly_vol = annual_vol ÷ √12　（年化 % → 月化小数）
路径生成：paths = base × exp(cumsum(N(0, σ_m, (1000, 12)), axis=1))
区间　　：conf_low = percentile(paths, 5, axis=0)　conf_high = percentile(paths, 95, axis=0)

计量逻辑详细梳理

3.1 训练集/测试集的切分策略

三种算法都不是标准的时间序列切分，而是「按固定期数切」： 线性回归用前 12 期训练、后 12 期当测试；逻辑斯蒂用前 18 期训练、后 6 期预测。 这种切分牺牲了严格的时间序列语义（测试集紧邻训练集，无 gap）， 但换来了实现简单、预测期数可控。

线性回归 · 逐步推导

① 取数据　　actual = balance_data["actual"] 或合成 24 期
若训练数据为空 → 合成 actual = [100 + 2.5i + N(0,5) for i in range(24)]

② 切分　　　train_y = actual[:12]　　test_x = arange(12, 24)
train_x = arange(12).reshape(-1, 1)

③ 构造设计矩阵　A = hstack([train_x, ones_like(train_x)])　// 加常数列求截距

④ 最小二乘　coef, *_ = np.linalg.lstsq(A, train_y, rcond=None)
coef = [a, b]　→　y = a·x + b

⑤ 预测　　　predicted = ([x, 1] @ coef) for x ∈ [12, 24)

⑥ 评估　　　train_pred = A @ coef
MAE = mean(|train_pred − train_y|)
RMSE = sqrt(mean((train_pred − train_y)²))
R² = 1 − SS_res / SS_tot　（SS_tot=0 时取 0）

逻辑斯蒂增长 · 逐步推导

① 取数据　　actual 或合成 50 + 100/(1+e^(-(i-12)/3)) + N(0,2)

② 切分　　　y = actual[:18]　　x = arange(18)

③ 定义曲线　sigmoid(x, L, k, x₀) = L / (1 + exp(−k(x − x₀)))
L 饱和上限（业务天花板）
k 增长速率（越大越快）
x₀ 拐点位置（达到 L/2 的时点）

④ 非线性拟合　popt, _ = curve_fit(sigmoid, x, y, p0=[max(y)×1.2, 0.3, 10], maxfev=2000)
失败兜底：popt = [max(y), 0.3, 10]　（退化为近似，不报错）

⑤ 预测　　　test_x = arange(18, 24)　→　6 期
predicted = sigmoid(test_x, *popt)

⑥ 评估　　　同线性回归（MAE / RMSE / R²），额外输出 L / k / x₀

蒙特卡洛 · 逐步推导

① 取基准　　base = mean(actual[:12]) 或 100.0

② 取波动率　从 params 找 param_code 含 "VOL" 的参数（默认 0.1）
annual_vol = value ÷ 100　→　monthly_vol = annual_vol ÷ √12

③ 生成路径　rng = np.random.default_rng(42)　// 固定种子，结果可复现
shocks = rng.normal(0, monthly_vol, (1000, 12))
paths = base × exp(cumsum(shocks, axis=1))　// 几何布朗运动

④ 统计　　　predicted = paths.mean(axis=0)　　　// 期望路径
conf_low = percentile(paths, 5, axis=0)
conf_high = percentile(paths, 95, axis=0)

⑤ 打包　　　返回 extras = (conf_low, conf_high)　→　落库为两列

3.2 第四种：线性规划（对照）

环节实现
决策变量x = cp.Variable(3, nonneg=True) —— 3 维非负向量
目标函数cp.Minimize(cp.norm(x, 1)) —— 最小化 L1 范数（等价最小化资本占用）
约束sum(x) ≥ 100（规模下限）· x ≤ 80（单笔上限）
求解器cp.SCS（锥优化通用求解器）
降级ImportError → 固定输出 [33.34, 33.33, 33.33]，metrics 标记 solver=fallback
输出predicted 3 期 · metrics 含 solver / optimal_value · 无置信区间
当前是演示实现：约束是硬编码的固定值，不读取 params、不读取训练数据。 接入真实场景需要把约束参数化（从 prcp_model_param 读取规模上下限）。

3.3 三个算法的适用场景与选型建议

算法数据形态要求 输出形态典型业务
线性回归≥ 12 期且呈线性趋势点预测（12 期） 贷款规模趋势外推、余额线性增长的科目

对指标计量的衔接

KPI

5.1 三条衔接路径

路径连接点 方向说明
①prcp_model.kpi_scheme_id → prcp_kpi_scheme.id 模型 → 指标方案 模型归属于某个指标方案，决定它服务哪一套指标口径
②prcp_model_param.kpi_id → prcp_kpi_definition.id 参数 → 指标定义 参数可以挂在具体指标上；也可不挂（纯算法超参）
③prcp_model_train_result.rpt_item_id=0 → SUMMARY 结果 → 报表（汇总） 预测值写入虚拟汇总项，与报表体系衔接

5.2 路径② 的参数化：参数如何服务于指标

prcp_model_param（版本级参数）
　　├── version_id　　→ 归属哪个模型版本
　　├── kpi_id　　　　　→ 关联的指标定义（可空 = 纯算法超参）
　　├── kpi_code　　　　→ 指标编码（冗余快照）
　　├── param_code　　→ 参数编码（VOL / EPOCH / SPLIT_RATIO …）
　　├── param_type　　→ BASE / 可扩展
　　├── param_category → 6 大分类（见第 8 章）
　　├── param_value　　→ 数值（训练时被引擎读取）
　　├── param_value_str → 字符串值（枚举类参数）
　　├── formula　　　　→ 参数字段的计算公式（如 base_balance × 0.05）
　　└── formula_desc　　→ 公式说明
关键设计：param.formula 让参数不只是常量， 还可以是引用其他数据源计算出来的表达式。 这是模型与「指标计量」体系衔接的通道 —— 参数可以从 prcp_data_basic（余额）、prcp_kpi_value（指标值）、 *_param（折算系数）派生。

5.3 模型的输入数据与指标计量同源

数据模型取数 指标计量取数关系
余额prcp_data_balance（L1 节点 SUM） prcp_data_basic（按 node_code） 同源不同表：balance 是按月快照，basic 是基准日快照
指标值不直接取（可经 param.formula 间接） prcp_kpi_value（公式/函数引擎算出） 模型当前不直接消费指标值，是能力缺口
折算系数不直接取 prcp_lcr_param 等 6 张参数表 指标函数脚本专用
⚠️ 能力缺口：模型不消费指标值
当前训练只读 prcp_data_balance 的总资产序列， 无法用「LCR 预测值」「ROE 预测值」作为训练特征， 也无法做「以指标为约束的模型」。 打通方式有两条：
  • 扩展 _load_balance_data：增加 metric_series 返回值， 从 prcp_kpi_value 取同指标多期值
  • param.formula 引用：把指标值作为参数参与算法（如蒙特卡洛的漂移项）

对指标评分的衔接

Score

6.1 评分体系的三段结构

层级表 关键字段作用
规则prcp_kpi_score_rule calc_method · total_score · higher_is_better 定义评分算法（分段/线性）、满分、方向
分段prcp_kpi_score_segment min_value · max_value · score · score_min 区间 → 分数映射，支持段内插值
评分prcp_kpi_value.score score decimal(8,2) 挂在指标值行上，与 current_value 同行

6.2 两种评分算法

算法段语义 计算式适用
PIECEWISE[min, max) 区间 score_min + (x−min)/(max−min) × (score−score_min)
score_min 为空 → 取该段 score（阶梯）		 监管指标档位评价（LCR/CET1 等）
LINEAR(x, score) 锚点对 y1 + (x−x1)/(x2−x1) × (y2−y1)
超出端点 → clamp		 平滑线性评分（ROE 等）

6.3 模型的预测值如何参与评分

评分引擎的入口接受 value，与来源无关 —— 这正是模型接入的关键：

评分入口　POST /prcp/api/kpi/score-calc　{ "rule_id": 51, "value": 123.45 }
　　　　　　value 可以是：① 实测指标值　② 模型预测值　③ 情景模拟值

模型→评分　predicted_value ──→ value ──→ 区间命中 ──→ 插值 ──→ score
　　　　　　　（语义完全一致，评分引擎无需知道值从哪来）

6.4 三种模型的评分适配性

模型输出 评分适配要点
线性回归点预测可直接评分 点估计代入规则即可；无区间信息，无法给出「得分的不确定性」
逻辑斯蒂点预测可直接评分 同上；但 S 形饱和意味着预测后期分数会趋于稳定，符合业务直觉
蒙特卡洛点预测 + 90% 区间 可算三档得分 用 conf_low/predicted/conf_high 分别评分
→ 得到悲观 / 中性 / 乐观三个分数，这是最有价值的用法
