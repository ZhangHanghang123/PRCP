> **页面地址**：https://wxfzhh.online/prcp/dashboard

## 一、页面定位

**入口**：左侧菜单「反算决策 / 组合反算」→「组合反算·结果驾驶舱」tab
（路由 `/reverse-dashboard`，是 `ReverseCalc.tsx` 的"结果驾驶舱" tab）

**核心价值**：将组合反算方案（`prcp_reverse_scheme`）的运行结果，用驾驶舱形式可视化呈现。同一页面内可切换方案/Run/预测月份，实时看到 KPI 快照、24 月趋势、大类分布、节点热力图、Top 10 节点、风险预警。

```typescript
function fmtMoney(v: number | undefined): string {
  if (v == null) return '-'
  const a = Math.abs(v)
  if (a >= 1e8) return (v / 1e8).toFixed(2) + ' 亿'
  if (a >= 1e4) return (v / 1e4).toFixed(2) + ' 万'
  return v.toFixed(2)
}
```

### 5.3 关键 SQL（snapshot 接口节选）

```sql
-- 1. 方案 + 账户册
SELECT s.id, s.coa_scheme_id, c.scheme_code AS coa_code
FROM prcp_reverse_scheme s
LEFT JOIN prcp_coa_scheme c ON c.id = s.coa_scheme_id
WHERE s.scheme_code = :sc AND s.is_deleted = 0

-- 2. 节点
SELECT id, node_code, node_name, node_level, path
FROM prcp_coa_node WHERE scheme_id = :s AND is_deleted = 0

-- 3. 当前月份余额/利率
SELECT coa_node_id, node_code, current_balance, avg_balance,
       weighted_rate, interest_amount, risk_weight
FROM prcp_data_reverse
WHERE scheme_code = :sc AND run_id = :rid AND date_offset = :do
  AND offset_unit = 'M' AND is_deleted = 0

-- 4. 当前月份 5 指标（兼容 fallback 到任意 scheme_code）
SELECT node_code, metric_type, current_value
FROM prcp_metric_coefficient
WHERE is_deleted = 0 AND scheme_code = :sc AND data_date = :dd
  AND node_code IN (:n1,:n2,...) AND metric_type IN (:m1,:m2,...)

-- 5. 24 月趋势
SELECT date_offset, data_date FROM prcp_data_reverse
WHERE scheme_code = :sc AND run_id = :rid AND offset_unit = 'M' AND is_deleted = 0
GROUP BY date_offset, data_date ORDER BY date_offset ASC

-- 6. KPI 评分
SELECT d.kpi_code, d.kpi_name, v.current_value, v.score,
       s.min_value AS seg_min, s.max_value AS seg_max, s.segment_desc
FROM prcp_kpi_definition d
LEFT JOIN prcp_kpi_value v ON v.kpi_id = d.id AND v.data_date = :bdd AND v.is_deleted = 0
LEFT JOIN prcp_kpi_score_rule r ON r.kpi_id = d.id AND r.is_deleted = 0
LEFT JOIN prcp_kpi_score_segment s ON s.rule_id = r.id AND s.is_deleted = 0
       AND (s.min_value IS NULL OR v.current_value >= s.min_value)
       AND (s.max_value IS NULL OR v.current_value <  s.max_value)
WHERE d.is_deleted = 0 AND d.kpi_code LIKE 'REG_%'
```

### 5.4 后端计算逻辑

```python
# 节点分类（基于编码前缀兼容 ZXCOA_V1 和 ZX_COA）
def _classify(node_code: str, path: str) -> str:
    if code.startswith("S01") or code.startswith("ZX_A") or path.startswith("/L1_资产"): return "ASSET"
    if code.startswith("S02") or code.startswith("ZX_L") or path.startswith("/L1_负债"): return "LIABILITY"
    if code.startswith("S03") or code.startswith("ZX_E") or path.startswith("/L1_权益"): return "EQUITY"
    if code.startswith("S04") or path.startswith("/L1_表外"):                        return "OFF_BALANCE"
    return "OTHER"

# 贷款加权平均利率（境内各项人民币贷款下 5 个 L4 子节点按余额加权平均，不含 L3 父节点）
# 取 S01010101* / S01010102* / S01010103* / S01010104* / S01010105* 开头的节点
loan_weighted_rate = Σ(balance_i × rate_i) / Σ(balance_i)

# 风险预警阈值
THRESHOLDS = {
    "CET1":      {"min": 8.5,  "direction": "down"},
    "LCR":       {"min": 100,  "direction": "down"},
    "NSFR":      {"min": 100,  "direction": "down"},
    "ROE":       {"min": 11,   "direction": "down"},
    "DELTA_EVE": {"max_abs": 5.0, "direction": "abs"},
}
# 严重程度：critical = <0.9×thr 或 |val|>1.2×thr_abs；warn = 介于两者之间
```

### 6.3 关键 Java 实现要点

1. **`_classify` 函数**：用 Java switch + String.startsWith 改写
2. **动态 IN 占位符**：MyBatis 用 `<foreach>` 拼接 `node_code IN (...)` 和 `metric_type IN (...)`
3. **KPI 阈值常量**：用 `@ConfigurationProperties` 或 `@Value` 注入
4. **fallback 逻辑**：metric_coefficient 先按 scheme_code 查，无数据时去掉 scheme_code 条件重查（兼容 ZXCOA_V1 历史数据）
5. **贷款加权平均利率**：用 `BigDecimal` 累加 `balance.multiply(rate)`，避免浮点误差
6. **24 月趋势**：用 `Map<data_date, Map<metric_type, List<value>>>` 双层分组聚合
7. **风险预警**：遍历 node_matrix，对每个节点的 metric_values 做阈值判断（critical / warn）
8. **响应 VO**：用 Lombok `@Data`，注意 `LocalDate` 序列化格式（与 Python `isoformat()` 一致：`yyyy-MM-dd`）
9. **指标评分**：注意 `prcp_sim_run` 表没有 `is_deleted` 列（Python 版踩坑过）

### 6.4 SQL 兼容性

Python 版用 SQLAlchemy `text()` + `:param` 占位符。Java 版用 MyBatis `#{}` 占位符即可。

**注意**：
- `prcp_data_reverse` 字段 `record_id` 主键是 `varchar(128)` 不是 bigint
- `prcp_coa_node` **没有** `parent_code/is_leaf/category` 列，只有 `parent_id`
- `prcp_rpt_item` 的外键列是 `report_id`（不是 `rpt_id`）
- `prcp_reverse_run_log` **没有** `is_deleted` 列
- `prcp_metric_coefficient` 的主键是 `id` (varchar 128)，字段是 `node_id` (int)，不是 `record_id/coa_node_id`

### 6.5 前端迁移建议

Java 后端只需实现 4 个 API（与 Python 版接口契约一致），前端可保留 React/TypeScript 代码：
- `reverseDashboardApi.options()` → `GET /api/reverse-dashboard/options`
- `reverseDashboardApi.runs(schemeCode)` → `GET /api/reverse-dashboard/runs?scheme_code=X`
- `reverseDashboardApi.dates(schemeCode, runId)` → `GET /api/reverse-dashboard/dates?scheme_code=X&run_id=N`
- `reverseDashboardApi.snapshot({...})` → `GET /api/reverse-dashboard/snapshot?scheme_code=X&run_id=N&date_offset=12`
