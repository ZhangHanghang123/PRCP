# 中信银行 7 指标 4 档评分标准说明

> **版本**: v11 · **生成时间**: 2026-10-10 · **适用对象**: 中信银行 2025 年末 / 2026 H1

---

## 一、评分框架总览

### 1.1 核心目标达成情况

评分首要衡量方案对**预设核心目标**的达成度：

| 目标维度 | 关键指标 | 说明 |
|---|---|---|
| 资本充足率 | CET1 ≥ 8.7% (7.5+0.5+0.7) | 监管硬约束 + D-SIBs 加点 |
| 规模 | 总资产 / 各项贷款余额 | 与战略目标一致 |
| 利润 | 净利润 / ROE / NIM | 与年度经营计划一致 |

评分采用 **达成值 + 偏差率** 双重校验：达成值反映绝对水平，偏差率反映相对偏离。

### 1.2 三维度摆布方案

| 维度 | 含义 | 摆布范围 |
|---|---|---|
| **规模维度** | 各资产、负债品类规模 | 各项贷款 / 债券投资 / 同业资产 / 客户存款 / 同业负债 等 57 行账户册 |
| **价格维度** | 各产品的定价 | 各项利率 (LPR 上下浮 / FTP 曲线 / NCD 利率 / 同业利率) |
| **期限维度** | 各产品的期限、缺口 | 久期 / 重定价期限 / 缺口分析 (影响 EVE 评分) |

三维度摆布构成 7 指标评分的**输入参数**，评分反映摆布方案的合理性。

### 1.3 评分制核心原则

- **4 档制**: 红线 (-500) / 危险-重惩罚 / 预警-轻惩罚 / 安全 (90-100)
- **监管硬约束**: 不满足监管线直接判 -500 彻底淘汰
- **平滑性约束**: 相比上一期变动过大按系数扣分 (5-10pp: -15-30/pp, >10pp: -60/pp)
- **7 指标加权**: LCR 18% / CET1 18% / NSFR 14% / EVE 13% / ROE 13% / IBL 12% / LR 12% = 100%

## 二、四性指标全景

按图中所示的"四性指标"框架，将 7 指标归类为四性 + 结构性 + 资本充足：

| 四性 | 涵盖指标 | 指标数 | 权重 | 红线 |
|---|---|---|---|---|
| 🟢 **盈利性** | ROE (净资产收益率) | 1 | 13% | < 6% (硬约束) |
| 🟠 **安全性** | EVE (银行账户利率风险) | 1 | 13% | > 15% (监管) |
| 🔴 **政策性** | CET1 (核心一级资本充足率) | 1 | 18% | < 8.7% (7.5+0.5+0.7) |
| 🔵 **流动性** | LCR (流动性覆盖率) | 1 | 18% | < 120% (本行底线) |
| 🔵 **流动性** | NSFR (净稳定资金比例) | 1 | 14% | < 100% (监管) |
| ⚙️ **结构性** | IBL (同业负债占比) | 1 | 12% | > 33.33% (监管) |
| 🏛️ **资本充足** | LR (杠杆率) | 1 | 12% | < 4% (银保监) |
| **合计** | | **7** | **100%** | |

> **说明**: 后续可扩展盈利性指标 (ROA / RAROC / NIM) 形成完整的盈利性多维度评估。

## 三、4 档评分规则详解

### 3.1 通用 4 档划分

| 档位 | 分值区间 | 含义 | 处理建议 |
|---|---|---|---|
| 🔴 **红线** | -500 | 触发监管 / 硬约束 | 立即终止方案，紧急调整 |
| 🟠 **危险-重惩罚** | 10-60 | 距红线 0-1 档 | 大幅调整，强约束扣分 |
| 🟡 **预警-轻惩罚** | 60-90 | 距红线 1-2 档 | 适度调整，提示风险 |
| 🟢 **安全** | 90-100 | 完全合规 满分 | 保持现状 |

### 3.2 各指标分档详情

#### LCR 流动性覆盖率 (权重 18%, 监管 ≥ 100%, 本行 ≥ 120%)
| 区间 | 档位 | 得分 |
|---|---|---|
| < 100% | 红线 | -500 |
| 100-120% | 红线 (本行底线未达) | -300 ~ -50 |
| 120-130% | 危险-重惩罚 | 10-40 |
| 130-140% | 预警-轻惩罚 | 70-85 |
| **140-150%** | **🟢 安全 适度最优** | **100** |
| 150%+ | 安全 (过高减分) | 95 → 65 |

> 💡 LCR 适度最优原则：LCR 太高 (≥ 150%) 意味着资金闲置，未投入到生息资产。

#### NSFR 净稳定资金比例 (权重 14%, 监管 ≥ 100%)
| 区间 | 档位 | 得分 |
|---|---|---|
| < 100% | 红线 | -500 |
| 100-103% | 危险-重惩罚 | 35 |
| 103-105% | 预警-轻惩罚 | 65-85 |
| **105-107%** | **🟢 安全 适度最优** | **100** |
| 107%+ | 安全 (过度稳定) | 95 → 75 |

#### EVE 银行账户利率风险 (权重 13%, 监管 ≤ 15%, 越低越好)
| 区间 | 档位 | 得分 |
|---|---|---|
| > 15% | 红线 | -500 |
| 12-15% | 危险-重惩罚 | 20 |
| 10-12% | 预警-轻惩罚 | 55-70 |
| 8-10% | 预警-轻惩罚 | 80-88 |
| **6-8%** | **🟢 安全 适度最优** | **96** |
| < 6% | 安全 (错失上行收益) | 95-98 |

> 💡 EVE 越低越好，但太低 (< 3%) 可能错失利率上行收益。

#### CET1 核心一级资本充足率 (权重 18%, 本行 ≥ 8.7%)
| 区间 | 档位 | 得分 |
|---|---|---|
| < 8.7% | 红线 | -500 |
| 8.7-8.8% | 危险-重惩罚 | 35 |
| 8.8-9.0% | 预警-轻惩罚 | 75-88 |
| **9.0-10%** | **🟢 安全 适度最优** | **100** |
| 10%+ | 安全 (过高 → ROE 承压) | 98 → 75 |

#### ROE 净资产收益率 (权重 13%, 硬约束 ≥ 6%)
| 区间 | 档位 | 得分 |
|---|---|---|
| < 6% | 红线 (硬约束) | -500 |
| 6-8% | 较低 | 40-60 |
| 8-9% | 行业中位 | 75 |
| 9-10% | 行业中上 | 82-88 |
| 10-12% | 优秀 | 92-96 |
| **≥ 12%** | **🟢 满分** | **100** |

> 💡 ROE 越高越好但需关注资产质量，过高可能伴随高杠杆风险。

#### IBL 同业负债占比 (权重 12%, 监管 ≤ 33.33%, 越低越好)
| 区间 | 档位 | 得分 |
|---|---|---|
| > 33.33% | 红线 | -500 |
| 30-33.33% | 危险-重惩罚 | -50 ~ 35 |
| 25-30% | 预警-轻惩罚 | 65 |
| **20-25%** | **🟢 安全** | **85-95** |
| < 20% | 安全 (过低 → 资金来源结构失衡) | 95 → 70 |

#### LR 杠杆率 (权重 12%, 银保监 ≥ 4%, 越低越不好)
| 区间 | 档位 | 得分 |
|---|---|---|
| < 4% | 红线 | -500 |
| 4-4.5% | 危险-重惩罚 | 30 |
| 4.5-6% | 预警-轻惩罚 | 60-80 |
| **6-8%** | **🟢 安全 适度最优** | **90-95** |
| 8%+ | 安全 (资本冗余 → ROE 承压) | 88 → 72 |

## 四、积分明细

### 4.1 综合得分公式

```
综合得分 = Σ(各指标得分 × 权重)
        = LCR × 18% + NSFR × 14% + EVE × 13% + CET1 × 18%
        + ROE × 13% + IBL × 12% + LR × 12%
```

### 4.2 评级体系

| 综合得分 | 评级 | 含义 |
|---|---|---|
| ≥ 90 | **A+ 卓越** | 所有指标均在安全区间, 经营稳健 |
| 85-90 | **A 优秀** | 关键指标达标, 偶有预警 |
| 80-85 | **B+ 良好** | 主要指标达标, 需关注预警项 |
| 70-80 | **B 中等** | 部分指标进入预警, 需调整 |
| 60-70 | **C 较弱** | 多项指标预警或危险, 大幅调整 |
| < 60 | **D 差** | 多项指标触发红线, 重新制定方案 |

## 五、风险提示机制

### 5.1 风险等级分类

| 风险等级 | 触发条件 | 页面提示 |
|---|---|---|
| 🔴 **极高风险** | 任一指标在红线 (-500) | "触发监管, 方案不可行" |
| 🟠 **高风险** | 任一指标在危险-重惩罚 (10-60) | "重大风险, 需立即调整" |
| 🟡 **中风险** | 任一指标在预警-轻惩罚 (60-90) | "需关注, 适度调整" |
| 🟢 **低风险** | 全部指标在安全 (≥ 90) | "风险可控" |

### 5.2 平滑性约束提示

如果方案相比上一期变动过大，触发平滑性扣分：

| 变化量 | 扣分系数 | 提示 |
|---|---|---|
| < 1pp | 0 | 业务可落地 |
| 1-3pp | -5/pp | 需注意 |
| 3-5pp | -15/pp | 业务论证 |
| 5-10pp | -30/pp | 大幅扣分 ⚠️ |
| > 10pp | -60/pp | 极端波动 ❌ |

## 六、调整建议

### 6.1 调整建议生成逻辑

若目标超预测区间，输出后续调整建议：

| 触发条件 | 调整方向 |
|---|---|
| 指标落在危险-重惩罚 | 重大调整，强制性 |
| 指标落在预警-轻惩罚 | 适度调整，建议性 |
| 指标在安全但接近上限 | 微调，提示性 |
| 指标变动幅度过大 | 平滑性建议 |
| 目标不可达 | 重新制定方案 |

### 6.2 中信银行具体调整建议

| 指标 | 现状 | 调整建议 |
|---|---|---|
| **EVE** | 10.54% (危险) | 优化久期缺口管理，压缩 2.5pp 至 8% 安全区间 |
| **CET1** | 8.98% (预警) | 补充核心资本 5-10 亿元进入 9.0%+ 安全区间 |
| **NSFR** | 104.52% (预警) | 微调负债结构 48bp 进入 105% 安全区间 |
| **IBL** | 21.60% (预警) | 适度压降同业负债 1.6pp 至 20% 安全区间 |
| **ROE** | 9.61% (预警) | 提升 ROA + 降杠杆，39bp 进入 10% 优秀区间 |
| LCR | 147.29% (安全略高) | 可适度下调 HQLA 配置到 130-140% |
| LR | 7.06% (安全) | 保持当前水平 |

### 6.3 综合调整优先级

1. **🔴 优先**: EVE 久期管理 (55 分, 短板)
2. **🟠 次优**: CET1 核心资本补充 (88 分, 接近 9% 安全线)
3. **🟢 优化**: NSFR / IBL 微调 (各 85 分, 距安全线 0.5-1.6pp)
4. **🟢 锦上添花**: ROE 提升至 10%+

### 7.3 后续扩展

- 盈利性指标可扩展: ROA / RAROC / NIM (目前只有 ROE)
- 政策性指标可扩展: 一级资本充足率 / 总资本充足率
- 资本充足可扩展: 资本充足率 / RAROC 风险调整

### 7.4 与反例测算配置的关联

本评分标准与**反例测算**模块联动：

- **输入**: 三维度摆布方案 (规模/价格/期限) → 7 指标预测值
- **处理**: 应用 4 档评分 + 平滑性约束
- **输出**: 综合得分 + 评级 + 风险提示 + 调整建议

底部截图反例: 净利润 4280亿 / 总资产 60493亿 / CET1 8.95% / 综合得分 87.45
